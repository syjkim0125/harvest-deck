# Harvest Deck — Godot Feel Lab v0.7.19

Godot 4 + GDScript. 저장소 없이 시작한 독립 프로젝트입니다.

## 실행

Godot 4.6.3 일반판에서 `project.godot`을 가져온 뒤 F6 대신 F5로 실행합니다.
v0.6까지 Linux 데스크톱에서 키보드 이동·수확·납품·응대·현금 회수를 확인했습니다.
v0.7 해금과 HUD 변경은 headless 검증이며 이번 새 프로젝트의 창 표시는 미확인입니다.
Mac·터치 기기·청음·사람의 손맛 평가는 아직 확인하지 않았습니다.

- WASD / 방향키: 이동. 진행 방향으로 가까운 과일을 자동 절삭합니다.
- 터치 드래그: 이동 코드 포함. 실기기 검증 전입니다.
- LAB의 민트색 JUICE 원: 순차 납품 → 과일별 FIFO 가공(0.45초) → 완제품.
- 파란 STAND TO SERVE 원: 서 있는 동안 손님에게 1개씩 응대·판매(0.7초).
- 산호색 MIXER 원: 회수한 현금 $40로 F키 또는 HUD 버튼을 눌러 1회 강화(0.45→0.25초/개). 진행 중 작업의 진행률 유지.
- 보라색 HIRE 원: 회수한 현금 $30로 E키 또는 HUD 버튼을 눌러 계산원 고용. 이후 자동 응대.
- 호박색 ORCHARD 원: 회수 현금 $50로 G키 또는 HUD 버튼으로 오른쪽 노란 과일 구역 해금.
- 금색 COLLECT 원: 판매대금 회수. 가방 초과 보상은 바닥에 남고 가까이 가면 줍습니다.
- 1: 화면 흔들림, 2: 전체 음향, 3: 대상 반동·번쩍임, 4: 25ms 대상 국소 정지.
- 6: 두 과일의 새 아트/이전 절차 도형 비교.
- 5: 연속 엔진/부하음만 ON/OFF. - / =: 볼륨 조절(기본65%).
- 화면 PAUSE/RESUME: 키보드 없이 정지·재개. 포커스를 잃어 멈춘 뒤에도 화면에서 재개 가능.
- M: 화면 흔들림 없는 reduced-motion. P / Esc: 일시정지·재개. R: 초기화.

## 지금 구현한 범위

이동, 기본 과일·해금 과일의 반복 절삭, 다수 동시 명중, 실제 명중별 제한된 카메라 흔들림,
직접 합성한 타격음·엔진/명중 부하음 루프, 피격 반동·번쩍임, 입자, 재료 적층·흔들림, 적재 한도,
귀환 납품, 재료/가공/완제품 분리·판매대금 회수, 재생성, 효과별 비교 토글.

현재 그래픽은 생성한 과일 정지 스프라이트와 코드로 그린 캐릭터·환경을 함께 사용합니다. 원본 게임 에셋은 사용하지 않습니다.
LAB에서 손님은 최대 5명의 FIFO 줄로 도착하고 완제품 1개를 구매합니다. 수확 직원은 아직 없습니다. 계산원은 $30로 한 번 고용할 수 있습니다.
기본 게임에서 첫 낮과 밤, 두 메뉴, 마감을 플레이할 수 있습니다. 카드와 3일 런은 다음 단계입니다.
