# 디자인 참고 인덱스

[ART_DIRECTION](ART_DIRECTION.md) · [REFERENCE_ROUTER](REFERENCE_ROUTER.md) · [VISUAL_REFERENCE_BOARD](VISUAL_REFERENCE_BOARD.md). 현재 자동 디자인 작업 중지. 우주 항해: 탑다운 회화적 2D, 함선 방향/동작/거리와 발견 단서. 행성 탐험 및 지상 전투는 쿼터뷰 승인(D18), 동일 공간 기본(D20); 정확한 카메라/화면·함내/거점 시점은 미확정. [통합 이미지 갤러리](planning/REFERENCE_GALLERY.md). 원본 게임 화면을 복제하지 말고 장면별 원리를 비교. 인게임 시안과 스토리보드의 사용자 승인 이후 구현.
