# 디자인 참고 인덱스

[ART_DIRECTION](ART_DIRECTION.md) · [REFERENCE_ROUTER](REFERENCE_ROUTER.md) · [VISUAL_REFERENCE_BOARD](VISUAL_REFERENCE_BOARD.md). 통합 개발 실행 내 디자인 병행([실행 계약](DEV_EXECUTION_CONTRACT.md)). 우주 항해: 탑다운 회화적 2D, 함선 방향/동작/거리와 발견 단서. 행성 탐험 및 지상 전투는 쿼터뷰 승인(D18), 동일 공간 기본(D20); 함내 쿼터뷰+가림 해제/전체 배치도 D47 승인; 정확한 카메라·화면·조작 규격은 미확정. [통합 이미지 갤러리](planning/REFERENCE_GALLERY.md). 원본 게임 화면을 복제하지 말고 장면별 원리를 비교. 승인된 방향의 가역적 인게임 시안·스토리보드·구현 병행, 최종 디자인은 별도 승인.
