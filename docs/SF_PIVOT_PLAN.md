# SF 행성 탐험 × 외계 생물 동료 × 우주선 상점 — 새 개발 방향 (승인됨)

> **2026-11-25 사용자 요청에 따른 공식 콘셉트 전환**. 이 문서는 기존 과일/체인소/뱀파이어 서바이벌 중심 Harvest Deck의 기능 확장보다 우선한다. **개발 착수 승인**이며 구체적 전투 조작의 최종 채택은 실제 비교 실험 후 결정한다. 프로젝트 이름은 아직 가칭이고 GitHub `syjkim0125/harvest-deck`은 개발 자산과 이력을 보존하기 위해 당분간 유지한다. 기존 게임 구현/배포가 새 콘셉트라고 주장하지 말 것.

## 1. 게임 판타지 / 한 문장 피치

플레이어는 **떠돌이 우주선의 선장 겸 장비 상인**이다. 외계 행성에서 의뢰를 받고 위험한 몬스터를 사냥·탐험하여 부품과 재료를 구하고, 귀여운 외계 생물을 친구로 데려온다. 귀환 후 우주선의 실제 설비에서 **총·갑옷·보급품**을 제작하고 방문객에게 판매한다. 번 돈으로 **우주선 객실·제작대·상점·동료 숙소**를 확장하면 다음 탐험의 선택지가 바뀐다. 탐험/제작 카드를 통해 능력·레시피·동료 상호작용을 덱빌딩으로 연결한다.

**폐기/보류:** 수박·귤·체인소·주스 판매와 Vampire Survivors식 자동 사냥을 새 게임의 핵심 장르로 강제하지 않는다. 과거 버전은 기능·타격감 기술 레퍼런스로만 보존. '낮/밤' 대신 '행성 원정/우주선 귀환'이라는 대비를 사용한다. SF 방향을 이 요청의 현재 우선안으로 채택하되, 아트·게임 명칭·조작은 플레이 테스트로 다듬는다.

## 2. 게임의 5개 핵심 기둥 (모두 플레이에 보여야 함)

1. **손맛과 숙련이 있는 원정 전투**: 적의 공격 예고→회피/패링 또는 위치 이동→반격/콤보→눈에 보이는 부품 드롭. 버튼만 눌러 자동 사냥하거나 체력 수치가 줄어드는 연출만으로는 합격 아님.
2. **고유 행동이 있는 수집형 동료**: 귀여운 외계 생물과 신뢰를 얻거나 구조해 동료로 모집한다. 한 동료가 원정 지원 또는 우주선 제작/판매 보조 중 역할을 선택하게 하고, 실제 화면에서 일을 한다. 포획 시 동료화 규칙은 게임 내 공감·관계의 느낌을 유지.
3. **물리적으로 성장하는 우주선 상점**: 재료→제작 작업대→장비 완성→진열/의뢰 납품→고객 구매→돈→새 모듈 건설이 한 화면(또는 연속된 공간)에서 확인된다. 단순 정산 수치 + 메뉴 버튼만 추가 금지.
4. **상호 연동 덱빌딩**: 원정 카드(무기 모듈/움직임·전투 기술/동료 능력)와 제작·판매 카드(레시피/설비/고객·생산)로 다른 결정을 하며, 카드 선택이 탐험 경로와 고객 수요에 의미 있는 차이를 만든다.
5. **짧고 직관적인 모바일 플레이**: 첫 화면에서 설명 없이 출발·조작·전투·귀환·제작의 행동을 이해할 수 있어야 한다. 기존 세로 한 손 터치는 **초기 프로토타입의 기본 제약**으로 유지하되, 정통 벨트스크롤의 조작이 우수하다는 실증이 있으면 가로/양손 전환은 별도 사용자 선택으로 요청한다.

## 3. 전투 장르 결정 실험 (첫 순서)

기존 자동 사냥을 이어서 확장하지 않는다. **고전 D&D 아케이드/Absolum 같은 횡방향·깊이축 이동의 벨트스크롤 격투를 우선 기술 프로토타입**으로 검증하고, 세로 터치 제약 때문에 재미가 떨어질 경우 **작은 방 단위 탑다운 액션**과 비교한다.

- 공통 조건: 주인공 1, 같은 외계 적 2종(접근 근접형/예고 후 원거리형) + 미니 보스 1, 동일한 체력과 공격 피드백, 1개 전투 강화 카드, 60~90초 플레이. 적 패턴에는 분명한 전조, 판정, 안전 지대, 반격 보상이 있다.
- **A안 벨트스크롤**: 2~3개 깊이 라인과 횡 이동, 접근·회피·반격·경직/넉백/콤보. 세로 화면에서 화면 밖 적·시야 손실을 테스트한다. 첫 조작은 한 손 드래그/탭·짧은 플릭 같은 소수 입력으로 시도한다. 순수 자동 공격만으로 끝나지 않게 플레이어의 타이밍 판단을 넣는다.
- **B안 소규모 아레나**: 같은 적/보상/카드, 방 단위 전투·회피·반격. 사용법 설명을 추가하지 않고 직접 조작 발견 가능성 비교.
- 기존 승인된 타격감 기술(hit feedback, impact pause, shake, sounds, particles)의 아이디어는 이식하되 기존 과일·체인소 에셋과 레퍼런스 게임의 저작물을 재사용하지 않는다.
- **채택 기준**: 조작 오류, 맞았을 때 이유의 이해, 회피·반격 성공 시 성취감, 초견 첫 15초 행동, 같은 방 3회 재시도 선호를 관찰. 자동 검사는 판정의 정확성을 보여줄 뿐 '재미 있다'고 증명하지 않는다. 실제 실기기·아동 사용성은 수행 전 '미검증'.
- 장르 확정은 이 비교에서 얻은 실증으로 결정. 바로 횡스크롤 장르로 전체 시스템을 강제 재작성하지 않는다.

## 4. 소규모 완결 MVP — 1개 행성, 1개 우주선

원정 전후 3~5분의 완전한 루프를 만들고 '다시 하고 싶다'는 동기를 검증:

1. 조종실의 **시각적 의뢰 카드**를 선택한다. 예: 사라진 수송대의 부품 2개 회수.
2. 외계 행성 한 지역(2~3개 작은 전투방)에 착륙, 적 전조·회피·반격으로 싸운다. 부품 2종을 얻는다.
3. 탐험 중 **외계 생물 1종과 동료가 되는 짧은 조작**을 한다. 동료를 전투에 데려갈지 우주선에 둘지 선택한다.
4. 우주선으로 복귀하면 **제작대에 재료를 드래그/탭**해 총 1종 또는 갑옷 1종을 실제로 완성한다.
5. 카운터에서 **장비 의뢰 납품/방문객 판매**를 한다. 상품이 진열대에서 손님에게 이동한다.
6. 번 돈으로 **작업대 확장 또는 동료 숙소 중 모듈 하나**를 건설한다. 확장 결과가 공간에 보이고 다음 원정의 장비/생산 능력을 바꾼다.
7. 다음 원정에서 **전투 카드 2선택/제작 카드 2선택** 중 적어도 1개의 의미 있는 갈등을 경험한다(동일 자원으로 공격력 vs 채굴량, 동료 전투 지원 vs 제작 등).

MVP에는 행성 1, 우주선 1, 외계 생물 1, 적 2+미니 보스 1, 장비 2종 이하, 모듈 업그레이드 1, 플레이 방식 차이 1, 의뢰 1만 포함. 다중 행성 대규모 우주 탐험, 온라인, 수집형 가챠, 20종 동료, 복잡한 절차적 생성, 텍스트 레시피 메뉴는 금지.

## 6. 이전 자산의 재사용/보존 지침

- **재사용 후보**: Godot 4.6.3 프로젝트 설정, 터치 입력, 기본 캐릭터 이동, 타격감 연출/검증 방법, 카드 뽑기·상태·덱 영속·손패·버림, 재고·판매·결제·진열 병목의 테스트 가능 로직, UI 터치 사이즈, 기존 자동 회귀 검사.
- **새 자산 필요**: 우주선·행성 배경, 주인공/외계 적/동료, 새 무기/탄착/회피 애니메이션, 제작실/판매 장비 시각물, 의뢰 아이콘, 새 세계관의 일관된 아트 디렉션.
- **보존**: v0.8.11 및 기존 `?lab=1` 경로와 Git 이력/테스트 결과. 안전하면 `legacy` 장면/메뉴로 유지하거나 전환 중 별도 경로를 확보. 새 게임 미완성 화면을 기존 플레이 가능 버전으로 잘못 표시하지 않는다.
- 실행 시작 때 최신 main, 진행 중 변경, `docs/ROADMAP.md`, `docs/HANDOFF.md`, `docs/REVIEW_BACKLOG.md`, 이 문서를 읽는다. 코드를 임의로 구버전 ZIP으로 덮어쓰지 않는다. **작업 자체가 실행 불가하면 이유와 그날 확인한 최신 상태를 명시**한다.

## 7. 리뷰 방향

이전 100점표의 구조를 유지하되 새 콘셉트로 항목을 재정의한다: 원정↔우주선 성장 연결(20), 전투·제작 덱빌딩 전략(20), 첫 90초 터치 UX(20), 외계 몬스터 전투의 타격감·숙련(15), 물리적 제작·상점/동료 운영(10), 패턴 발견·재플레이(10), 우주선·행성·외계 생물의 아트 일관성(5). 점수는 실제 증거가 있을 때만. 동료 수집과 우주선 공간 확장이 구현되지 않으면 이번 새 게임 핵심 시스템 누락(P1 이상)으로 추적한다.

참고 게임(분석 기준이지 자산 복제 대상 아님): Absolum / Dungeons & Dragons: Shadow over Mystara / Moonlighter / Cult of the Lamb / Monster Sanctuary / Cassette Beasts / Otherworld Legends / Dave the Diver / Cut the Rope.

## 8. 결정 기록

- **확정**: SF 행성 탐험, 외계 생물 사냥·모집, 우주선 장비 제작·판매·확장, 교차 덱빌딩의 새 게임으로 피벗. 기존 과일 체인소 장르는 더 이상 새 개발의 기준이 아님.
- **실험으로 결정**: 횡 벨트스크롤 vs 작은 방 액션의 조작 방식. 벨트스크롤 우선 개발.
- **잠정 유지**: 세로 화면·한 손 터치라는 UX 지향. 가로 전환은 실제 비교 후 사용자 승인 필요.
- **보류**: 정식 게임명, 전체 아트 스타일, 대형 맵/멀티플레이/광범위 카드 목록.
