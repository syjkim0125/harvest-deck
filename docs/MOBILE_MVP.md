# Harvest Deck 모바일 MVP 설계

## 한 판과 입력

낮은 최대 36초다. 적을 베면 재료가 바로 가방에 들어간다. 하트가 다 닳아도 모은 재료를 들고 밤으로 넘어간다. 큰 톱날은 사거리, 빙글 톱은 타격 방향, 앞치마는 하트, 과일 카드는 획득량을 바꾼다. 전투 카드는 별을 지불하거나 그때마다 다시 플레이할 필요 없이 선택 즉시 적용된다.

밤에는 카드 3장과 별 2개를 받는다. 가게가 열리기 전에는 시간이 흐르지 않는다. 카드를 믹서·진열대·계산대에 끌어다 놓거나 카드를 누른 후 빛나는 설비를 누른다. 일반 가공은 자동이며, 빠른 착즙 카드는 일반 주스 두 잔의 가공을 앞당긴다. 혼합 카드는 수박과 황금 과일을 한 개씩 써서 고가 주스를 넣는다. 도우미와 팁 병은 서로 다른 판매 효과를 낸다. 중간에 새 손패가 돌아오고 마감 뒤 첫날 보상 하나를 고른다. 둘째 밤 뒤 판매량과 매출로 한 판을 마친다.

아이콘·수량·설비의 위치로 다음 행동을 알려주고 짧은 한국어를 보조로 둔다. 조작해야 하는 카드는 320×560에서 약 89×105 화면 단위, 설비는 약 87×117 이상이다. 틀린 위치는 카드를 소비하지 않는다. Apple 44pt·Android 48dp 지침을 설계 기준으로 삼았다. 일곱 살 아동이 독립적으로 플레이할 수 있는지는 첫 실사용 테스트에서 확인할 과제다. [Apple 게임 디자인 지침](https://developer.apple.com/design/human-interface-guidelines/designing-for-games) · [Android 터치 영역 지침](https://support.google.com/accessibility/android/answer/7101858)
