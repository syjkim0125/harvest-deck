# 기획용 레퍼런스 라우터

[통합 GDD](LIVING_GALAXY_VISION.md) 우선. 레퍼런스는 원리 비교용, 원본 IP 복제 금지. 이미지/콘셉트/조작은 사용자 승인 전 미확정. 자동 구현 지시가 아니다.

| 영역 | 참고작 | 참고할 요소 |
|---|---|---|
| 세력·인물·정치 | Bannerlord | 자율 목표·외교·전쟁·영토 |
| 항해·교역·조우 | 대항해시대 / Black Flag | 직접 이동·발견·선택 |
| 항성계 화면 | Starsector (비교 후보) | 탑다운 함선·거리·조우 표현 |
| 탐험 | Zelda BOTW/TOTK | 시각적 단서·부분 정보·연쇄 발견·시스템 조합 |
| 함내·거점·동료 | RimWorld | 배치·자율 작업·개인 서사 |
| 지상 탐험 | Tunic + Zelda | 쿼터뷰 숨은 길·가림·환경 단서 (D18) |
| 지상 액션 | Absolum + Hades II | 공격 예고·명중·회피·반격; 쿼터뷰 전투(D18), 방/벨트스크롤 구조 강제 금지 |
| 함선 피해·승선 | FTL / Black Flag / Starsector | 핵심 기능 손상, 승선, 함대; 원작의 전체 모듈/별도 전투 화면 복제 금지 |
| 시각 표현 | Vanillaware | 회화적 레이어·실루엣·광원 |
| 모바일 조작 | Cut the Rope / Where's My Water? (비교 후보) | 설명 최소화·직관적 입력 |
