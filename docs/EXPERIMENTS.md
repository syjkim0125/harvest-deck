# Game feel experiments

현재는 실험 장치와 논리 검증만 완료. 주관적 전후 평가나 원본 동등성 결과 없음.

| 변수 | 토글 | 실험 가설 |
|---|---|---|
| 명중별 흔들림 | 1 | 연속 펄스가 절삭을 명확하게 전달하며 상한이 과도한 누적을 줄임 |
| 합성 충격음 | 2 | 피드백 시각과 같은 명중 이벤트의 소리가 타격 시점을 분명하게 함 |
| 대상 반동/flash | 3 | 다수 대상 중 무엇이 맞았는지 식별 가능 |
| 대상 국소 정지25ms | 4 (기본OFF) | 전역 이동/생산을 늦추지 않고 짧은 강조 가능 |
| 흔들림 제거 | M | 이동/수확 결과를 유지하며 피로감을 줄일 대안 |

정지25ms는 60fps 물리에서 양자화되고 대상 복귀 모션만 정지한다.
완성된 공격 애니메이션의 히트스톱이 아니며 연구에서 검증된 최적값도 아니다.
공격/이동/판매 simulation을 멈추거나 Engine.time_scale을 변경하지 않는다.
v0.1~0.3 음향은 짧은 합성 충격음만 있었고, v0.4부터 체인쏘우 엔진/절삭 루프도 구현됨.

## 같은 조건 비교 방법

R로 시드/월드 초기화 → 왼쪽 과일 군집으로 이동 → 10초 수확 → 납품.
한 변수씩 변경하고 타격감/가독성/조작성/피로감(각1~5)·시간·수확량·실제 fps를 기록.
reset 시 토글은 유지되므로 비교 조건을 표기할 것. v0.1에는 키보드 방향/타이밍 자동 리플레이 미구현이었고 v0.2부터 tests/feel_replay.gd 제공.
테스트 프레임률은 simulation delta 비교이며 실제 GPU 30/60/120fps 측정이 아니다.

## v0.4 음향 실험 구현 / 2026-11-17
공식 AudioStreamWAV 문서의 동적PCM/샘플 단위 loop_begin·loop_end와
AudioStreamPlayer의 volume_linear/pitch_scale/max_polyphony를 확인해 적용.
- https://docs.godotengine.org/en/stable/classes/class_audiostreamwav.html
- https://docs.godotengine.org/en/stable/classes/class_audiostreamplayer.html
엔진 API 근거이며 인간 타격감 향상의 실증 연구는 아니다.

엔진은 idle/movement 피치, 절삭 레이어는 실제 명중으로만120ms 유지.
12ms attack/55ms release, 엔진 gain0.10~0.20/부하 gain0.28, 기본전체65%는 설계 실험값.
계속 맞으면 루프 재생 위치를 매번 초기화하지 않고 gain을 유지.
헛스윙은 부하음을 새로 만들지 않고 직전 명중의 짧은 꼬리만 감쇠 가능.
2 전체음향 / 5 루프만 / -·= 음량으로 이전 충격음 단독과 비교 가능.
공간 음향은 아직 없고 플레이어 무기 전용 비위치 음향이다.

65개 회귀: 음소거/재개/pause/reset/focus-out/만재/실패 타격/30·60·120Hz envelope,
PCM 파형/루프 경계 기울기/동시2타격 포함 최대 PCM 합산 clipping 상한 확인.
이 검사는 장치 출력·청음·음악적 음질이나 멀미/피로감을 입증하지 않는다.
Headless에서는 출력 재생을 연결하지 않고 동일 상태/PCM 합성을 실행(명시적 코드 경로).
5효과 조건은 이전과 같은18초 경로이며 모두 명중39·재고26·판매4·현금회수20 유지.
주관 타격감·가독성·조작성·피로감 평점은 미측정.

## v0.5 회귀/자동화 확인
계산원은 기존 단일 응대 조건을 operator OR cashier로 바꾸며 시계나 속도를 늘리지 않음.
플레이어와 계산원이 함께 있어도 이중 판매 없음. 신규 손맛 파라미터 변경 없음.
같은18초 경로의 효과 비교 5조건은 고용을 하지 않으므로 이전 조건을 보존.
82검사는 미회수대금 구매불가/비용차감/중복구매/무재고/중복응대/최근이력 상한,
UI가 터치를 먼저 소비할 기회와 일시정지 시 직원중지를 포함.
300개를600초 시뮬레이션으로 처리해 종류별150판매/미회수1500/최근고객64명 유지.
600초는 논리 시뮬레이션이며10분 인간플레이/성능 측정이 아님.
실제 창에서는 현금40회수→30고용→잔액10→과일구역 수확9 중 미회수20 증가 확인.
원본타격감 향상/주관평점/청음 효과를 입증한 결과가 아님.

## v0.6 시설 비교와 입력 회귀
같은10재료/2초/응대없음 조건: 기본4완료, 강화8완료. 전체 재고10개 보존.
진행 중50%작업을 강화하면 새0.25초의50%=0.125초 경과 상태로 변환.
재료종류/재고/현금과30·60·120Hz 가공 결과를 검증. 인간 타격감 검증은 아님.
터치이동 시작→HUD가 해제 이벤트를 소비하는 경로를 추가하자83검사 중1개실패.
_raw 입력 단계에서 활성drag의 release만 먼저 해제하도록 수정 후99검사 통과.
UI 위 press는 여전히 이동을 시작하지 않으며 unhandled press는 정상 이동 시작.
모바일 실기기 테스트로 해석하지 않음. 기존5효과18초경로는 신규구매없이 동일결과.
