# VOID CARAVAN — 기획 핸드오프

현재는 기획 전용. [통합 GDD](LIVING_GALAXY_VISION.md)와 [공통 이슈 #10](https://github.com/syjkim0125/harvest-deck/issues/10)가 최신 기준이다. 기존 개발/디자인/리뷰 자동화는 중지. PR #4/#5/#6/#13은 기존 프로토타입 관련 작업으로 보류; 승인 없는 병합·확장 금지. 원본 코드, 에셋, 테스트, Git 이력은 보존. 기술적 검증 이력은 [RESEARCH_LOG](RESEARCH_LOG.md)와 이전 커밋에서 확인 가능하며 최신 제품 승인으로 사용하지 않는다. 현재 방향 불합격이며 CI와 사용자 경험 검증은 별개. 최종 승인 후에만 구현 계획·협업 규칙을 다시 확정.


[새 세션 인계](planning/SESSION_RESUME.md) 및 연결 자료를 먼저 읽는다. 승인/시나리오/시각자료/출처를 함께 갱신하고 재조회. 현재 위치는 [SESSION_RESUME](planning/SESSION_RESUME.md)의 단일 기록을 따른다(D34 승인, D35 미결).

추가 필수 자료: [대화 기록](planning/CONVERSATION_LOG.md), [실제 이미지·공식 미디어](planning/REFERENCE_EVIDENCE.md), [이론 적용](planning/THEORY_APPLICATION.md). 사용자 승인마다 원문/응답 요약 및 연결 근거를 갱신.
