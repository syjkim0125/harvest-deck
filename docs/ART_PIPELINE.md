# Art pipeline

현재는 Godot draw API의 도형/절차 애니메이션/직접 합성 오디오로 동작 검증.
원본 고유 그래픽·음원 추출 없이 기본 동작과 템포를 먼저 맞춘다.
완성 에셋이나 완성 애니메이션이라고 부르지 않는다.

차후 캐릭터와 세계관 확정 후 정지 콘셉트를 이미지 생성으로 제작하고,
방향별 모션/프레임 정합성/발 접지/판정 타이밍을 게임 속에서 검증.
픽셀아트는 아직 확정 아님. PixelFX 등 외부 도구는 필요할 때 공식 소스·라이선스·
지원 형식과 환경을 확인한 뒤 선별한다. 도구 도입 자체를 진행으로 세지 않는다.

v0.2도 절차 도형만 사용. 가공 진행바, 현금 회수 패드, 바닥 초과 재료를 추가.
스타일 확정/새 생성 에셋/방향별 완성 모션은 아직 없음. 외부 도구·라이선스 추가 없음.

v0.3: 도형 손님을 실제 고객ID와 연결하고 줄 이동을 보간. 응대 진행 링 추가.
이는 대기열 표현이며 방향별 걷기 애니메이션 완성이 아님. 새 외부/원본 에셋 사용 없음.

v0.4: 원본 오디오를 추출하지 않고24kHz PCM의250ms 엔진/절삭 루프를 코드로 합성.
정수 주기 사인파/고조파/별도 고정시드 위상으로 루프 경계를 연결.
명중별 짧은 충격음은 유지하며 두 음성까지 겹침 허용. 완성 사운드 디자인/청음 검증 아님.

v0.5: 보라색고용패드, 고용버튼, 계산원 도형 및 작은 팔 움직임 추가.
절차 도형/표현 동작이며 완성 직원 애니메이션이나 방향별 발접지 검증 결과는 아님.
추가 외부에셋/원본샘플/이미지생성 에셋은 사용하지 않음.

v0.6: 믹서 외형/회전 블레이드·산호색 강화패드·HUD 강화버튼 추가.
강화 후 베이스 색과 회전 속도를 바꿈. 절차 도형이며 완성 애니메이션 아님.
원본 에셋/새 외부 라이브러리/이미지 생성 에셋 추가 없음.
