# 시각 자료 보존 및 사용 계약
2026-11-28 · 사용자 D53 승인 시 요청. GDD·결정 이력이 구현 요구사항의 단일 기준이다.

## 승인마다 보존
- 선택지 비교, 구체 플레이 예시, 그룹/캐러셀의 **모든 실제 표시 이미지**, 자체 SVG·인터랙션을 대상으로 한다. 신규 외부 이미지는 표시 전에 정확한 URL·원본 페이지·출처·결정 ID·표시 순서·참고 요소·제외 요소·원본/권리 상태를 확보하고 manifest에 기록한다. 이미지 ref의 실제 URL/파일 미확인 시 미확보로 분류한다. 그룹 검색 문구 하나를 이미지 하나로 간주하지 않는다.
- 원본 파일은 실제 확보 가능한 경우에만 저장하고 파일 존재 및 해시를 검증한다. 공개 저장소에서 재호스팅 권리 미확인 시 원본 링크와 비공개 저장 가능 여부를 분리. 채팅 원본과 신규 대체 이미지를 동일시하지 않는다. 표시 후 원본 미확보 시 복구 대기에 남긴다. 원본 회수 시 대체 참고도 역사 기록 유지.
- 자체 도식/인터랙션은 실제 원본이 있으면 원본 보존, 재구성은 명시. 신규 이미지가 필요하지 않은 추상 기획은 자체 도식만 사용.

## 구현 시 노이즈 차단
| 분류 | 권한 |
|---|---|
| 확정 GDD/결정 | 구현 요구사항 |
| 사용자 선호 시안 | 아트/UX 콘셉트 우선 참고, 최종 승인 아님 |
| 선택된 방향의 일반 참고 | 지정한 요소에 한해 참고, 원작 기능 전체 채택 금지 |
| 미선택 대안 | 비교 역사만; 구현·디자인 근거 금지 |
| 최종 승인 아트 | 별도 명시 승인 후 실제 아트 기준 |

manifest의 role 필드는 신규 기록에 적용. 이전 기록의 role 누락은 미분류로 취급하고 자동 활성화 금지. status(active/deferred/historical)는 자료 생명주기이며 아트 승인 아님. 사용자 선호 priority와 최종 아트 승인을 구분. 개발 AI는 작업에 연결된 D번호의 GDD/결정/상세 예시와 명시적으로 선택한 참고만 조회하며 전체 갤러리, 복구 대기, 대안 자료를 기본 컨텍스트로 로드하지 않는다. 동일 이미지 URL/해시를 중복 저장하지 않고 여러 결정 연결 유지. 참고 과다 시 대표 1~3개만 작업 입력으로 선정하되 전체 아카이브는 보존한다.

## 현재 제한
D53 이전 응답에서 검색 문구 12개를 확인했으나 실제 렌더링된 모든 이미지 개수/파일/URL은 알 수 없다. 신규 웹 검색으로 얻은 REF-35~38은 대체 참고이며 원본 회수 아님. 과거 미확보는 [복구 대기](VISUAL_RECOVERY_QUEUE.md) 참조. 이번에는 원본 파일 다운로드/재호스팅하지 않았다. 자동화 재개나 게임 코드 변경을 승인하지 않는다.
