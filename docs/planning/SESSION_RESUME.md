## 변경 관리 계약
- [시각 자료 관리 계약](VISUAL_REFERENCE_POLICY.md): 모든 표시 이미지/그룹을 승인마다 보존한다. 미선택 대안·일반 참고·사용자 선호·최종 승인 아트를 분리하고 구현 세션은 해당 결정의 선택된 참고만 필요한 만큼 읽는다. 가능한 경우 표시 전에 출처·직접 이미지 URL·표시 순서를 기록한다. 원본 미확보/권리 미검증은 그대로 표기하며 대체 참고를 원본으로 간주하지 않는다.
- 승인마다 GDD(규칙), 결정 이력(승인 여부·이유), 대화 기록(사용자 원문), 상세 예시(시나리오·UI·표), manifest(이미지 ID·결정·출처·참고 목적·제외 범위·원본 상태)를 갱신. 선택지와 구체적인 플레이 예시에 표시한 모든 이미지의 출처·용도·원본 상태, 필요한 자체 이미지/인터랙션 원본, 연구 근거, 검증 가설도 함께 보존. 현재 위치는 이 페이지 기준; 역사적 미결 문장은 현재 상태로 사용하지 않는다.
