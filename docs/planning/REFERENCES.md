## D19 연결
기존 Tunic/젤다의 연결 지형과 발견 원리를 지속 지표에 참고하고 Hades II의 분기 공간은 일부 절차 생성 구역의 비교 후보로만 활용. Hades II의 전체 원정 초기화나 방 단위 강제 전투를 채택한 것은 아님. [D19 자체 설명 그림](visuals/19-planet-regions-procedural.svg). 새 외부 이미지 미사용.

## D20 연결
Tunic의 탐험 중 실시간 교전/실제 보스 구역을 비교하고, Zelda의 환경·행동 선택과 Absolum의 타격 피드백 원리를 참고. 기존 STEP 4-5 이미지 주제: Pokémon Legends Arceus encounter(별도 전투 비교), Tunic forest enemies, Tunic Siege Engine arena. 해당 채팅 이미지 실제 원본 URL 미확보; 새 이미지 검색/영상 검증하지 않음. [자체 도식](visuals/20-ground-encounter.svg).

## D21 연결
Absolum은 공격 입력·접촉·피격 반응의 참고, Hades II는 쿼터뷰 전투 비교, Cut the Rope/Where's My Water는 직관적 입력 원리, U-008은 모바일 입력/HUD 가독성 참고. PC/콘솔 버튼 배열을 복제하지 않음. 새 외부 이미지 미사용. [자체 조작 도식](visuals/21-ground-input.svg).

## D22 연결
Absolum 공격/반격/연계, Hades II 무기별 속도·범위·기동, Tunic 방어·회피를 원리 비교에 사용. 기존 STEP 4-8 대화 이미지 주제: Absolum parry counter, Hades II axe dodge, Tunic shield block; 회화적 SF 검/방패, 쌍검, 중량 해머, 에너지 소총, 드론, 외계 유물. 대화 이미지 원본 URL/파일 미확보이며 새 외부 이미지 검증 없음. [자체 도식](visuals/22-ground-combat-styles.svg).

## D23 연결
Absolum의 공격·피격 반응, Hades II의 무기별 리듬, 기존 Chainsaw Juice King의 절삭/충격 연구(이전 과일 게임의 시각 원칙만, 게임 루프 복제 금지), 기존 GDC Juice It or Lose It, U-005/U-007 타격 연구 활용. [원본 연구와 출처](../GAME_DESIGN_THEORY.md), [영상 증거와 검증 수준](../VIDEO_RESEARCH_INBOX.md), [자체 타격 도식](visuals/23-combat-impact-timing.svg). 새 외부 이미지/영상 검증 없음.
