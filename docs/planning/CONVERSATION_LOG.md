## 기획 재시작 맥락 (요약)
기존 프로토타입이 원하는 게임과 크게 달랐고 타격감과 탐험의 재미가 부족하다는 사용자 평가에 따라 개발 중심 반복을 중지. 새로운 게임 정체성부터 상세 기획을 재확정한 뒤 화면과 실제 조작 프로토타입을 승인하기로 함. 초기 결정 D01–D10의 상세 재구성은 DECISION_HISTORY에 보존. 사용자 지정 Zelda 영상은 원본 확인 대기. 초기 대화 전 문장의 축어록은 확보되지 않았음.

응답: 기존 승인 사항은 GDD에 있었으나 대화 이미지/세부 설명 일부 누락을 확인. 결정 이력·레퍼런스 색인·인계·자체 SVG 18개를 main에 실제 저장. 자동 이미지의 동일 원본 파일은 미확보, SVG는 재구성임을 명시.

> 응. 기획서에 그럼 우리가 나눈 대화와 결정 사항, 레퍼런스 게임들, 레퍼런스 게임들의 이미지, 관련 이론 등등 다 적어놔. 필요하면 게임 정보가 있는 사이트 연결링크까지... 그러면 괜찮지?

**문서화 계약:** 앞으로 확인 가능한 사용자 원문, 응답 요약/비교/선택 이유, 결정 ID, 승인 상태, 플레이 흐름, 실제 출처(공식/2차 구분), 참조 이미지 URL/원본 확보 상태, 자체 그림 원본, 이론 및 적용/검증 계획, 미결 항목을 보존. 모든 관련 문서와 다음 진행 위치를 한 번의 일관된 변경으로 갱신하고 main에서 재조회. 모든 이전 채팅 원문·이미지의 완전 복구를 주장하지 않는다. 이 요청은 문서 관리 승인이지 게임 개발 승인 아님.

## D19 승인 후 상세 논의 (2026-11-26)
자연환경, 정착지, 고대 유적, 동굴, 세력 거점, 미개척 지역은 후보. 행성별 특색을 유지하고 생성 공간의 구조를 저장하며 생태/자원/NPC 활동으로 변화를 주는 방향 제안. 수치 및 갱신 조건 미확정. D20은 지상 탐험과 전투의 연결 방식으로 이어감. C(동일 공간 기본 + 특정 장소의 별도 구역)를 제안하되 사용자 승인 대기.

## D20 승인 및 다음 결정 (2026-11-26)
> C. 동일 공간 전투 + 특수 전투 구역으로 기획하자.

일반 지상 교전과 탐험을 같은 공간에서 진행하고 보스·특수 유적은 실제 세계와 연결된 특수 구역으로 설계. 생명체가 플레이어를 위해 대기하는 몬스터가 아니라 먹이·영역·순찰 등의 목적을 가진다는 예시를 제안. 세부 생태/교전 규칙 미확정. 다음 D21은 지상 입력: A 전부 수동, B 기본 자동+수동 이동/회피/기술, C 직접 이동 및 수동 공격 중심+조준/연계 보조(추천, 미승인).

## D21 승인 및 다음 결정 (2026-11-26)
> C. 직접 이동·수동 공격 + 조준·연계 보조로 기획하자.

공격의 개시·타이밍은 수동, 조준/연계 보조는 입력 의도를 돕되 대신 공격하지 않음. 드래그 이동/터치 공격/스와이프 회피 등은 후보로 검증. D22 다음 선택: A 공격·회피 중심, B 공격·회피·가드·반격 공통 필수, C 공통 공격·회피+무기/직업별 방어·반격·연계(추천, 미승인).

## D22 승인 및 다음 결정 (2026-11-26)
> C. 공통 공격·회피 + 무기·직업별 방어·반격·연계로 기획하자.

공통 공격/회피를 유지하면서 무기·직업·능력별 대응과 연계에 차이를 둔다. 방어형/기동형/중량형/사격형/기술형/지원형은 예시이며 확정 직업/장비 목록 아님. D21 수동 공격 유지. 덱으로 새로운 행동/조합을 확장하는 방향은 제안. 다음 D23: A 빠른 연속 공격 중심 / B 무거운 한 방 중심 / C 무기·상황에 따라 차등화하되 입력 반응성 유지(추천, 미승인).
