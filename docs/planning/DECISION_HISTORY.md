# VOID CARAVAN — 상세 기획 결정 이력
2026-11-26 KST · 기획 재시작 이후 현재 대화에서 확인 가능한 결정의 재구성 기록. [GDD](../LIVING_GALAXY_VISION.md)가 승인 사항의 최상위 기준. 아래 비교·시나리오·수치는 승인된 방향을 설명하는 **기획 예시**이며 최종 수치/기능/화면 승인 아님. 전체 채팅의 원본 내보내기나 모든 이전 메시지/이미지 파일의 완전 복원은 아님.

## 재기획 시작
사용자가 기존 게임이 원하는 방향과 전혀 다르다고 평가. 기존 구현(고정 별지도→즉시 지상 전투, 텍스트 사건, 확률 점령)은 방향 불합격. 3개 자동화 중지, 기획→인게임 시각 시안→첫 10분 스토리보드/조작 프로토타입→승인→구현의 순서로 전환. [#10](https://github.com/syjkim0125/harvest-deck/issues/10), [정리 PR #14](https://github.com/syjkim0125/harvest-deck/pull/14). 기존 코드/에셋/테스트는 기술 참고로만 보존.

## 1. 은하계의 경험과 인과관계 (D01–06)
- 중립 선장으로 시작. 탐험가/상인/용병/해적/개척자/지도자는 고정 클래스가 아니라 삶의 방향. 명시적 최종 결말 강제 없음.
- 시간: 항해, 행성, 함내, 전투 진행 중 세계가 움직임. 앱 종료 정지. 일시정지/설정 정지, 수면·장거리 이동 시간 가속은 제안이며 상세 화면 시간 규칙 미결.
- 은하 전략 지도는 항성계/장거리 항로/위험/세력의 영토를 보여준다. 항성계에서 직접 조종하여 행성·위성·정거장·소행성·함대·미확인 신호 발견. 착륙/정거장/함선 조우/함내 공간은 같은 지속 상태. 강제 스테이지 전환 아님.
- NPC는 성격/목표/관계/직업·능력/자산/소속/경험에 따라 행동. 군주 외교·전쟁, 군함 순찰·호송, 상인 교역, 해적 약탈, 탐험가 조사, 용병 계약, 일반 주민 집단 생산·소비.
- 예시: 광물 행성 점령→공급 감소→가격 상승→교역로 변화→해적 집중→호송 의뢰. 장군 패배→군주와 관계 악화→탈퇴→정거장 확보→독립 세력. 플레이어와 상관없이 발생하고 개입 여부 선택.
- 초기 세계관 후보: Helion Directorate 정부(질서/군사), Vela Compact 상단(경제/물류), Ashline Freefront 반군(독립/기동), Choir of the Veil 종교(유물/연구), Dusk Corsairs 해적(밀수/기습), Outriders 중립 유랑(탐험/생존). 선악 고정 금지. 이름 붙은 기존 지도자는 영입 불가(기존 승인 제약).
- 보급, 경제, 통치, 충성, 외교적 견제, 지도자 계승, 기술이 세력 성장/쇠퇴를 만드는 후보. 인위적 세력 불멸/무제한 확장 금지.
- 직접 기획: 핵심 역사/세력/주요 인물/수도/역사 장소. 절차 생성: 주변 항성계·항로, 행성 환경, 일반 NPC, 자원, 유적의 일부. 희귀 생물은 직접 디자인+출현 조건 변화 후보. 시드 저장/재현.
- 환경 후보: 밀림(독성 식물·유적), 사막(폭풍·지하), 빙하(극저온·광물), 해양(수중·침몰 유적), 화산(열·에너지), 멸망 문명(폐허·기계). 환경은 색만 바꾸지 않고 다른 탐험 경험을 제공. 모든 유형 구현 승인 아님.

## 2. 실제 항해 (D07–11)
- 회화적 배경에 전/중/후 레이어, 성운/천체/잔해와 함선의 크기 대비. 카메라 추적/줌 후보. 문명 중심부(교역), 소행성(채굴/회피), 성운(탐지/은신), 미개척 우주(유적), 전장(구조/잔해), 우주 생태계(관찰/교감).
- 화면 어디서든 자유 드래그→선회/가속, 손을 떼면 가벼운 관성/감속. 정찰선은 민첩, 화물선은 묵직, 범용선/전투선은 다른 무게감. 조준/충돌/도킹 보조는 제안. 7세도 직관적으로 이해하는 것이 목표이지 검증된 결과 아님. 세로 모바일 한 손, 버튼 최소화.
- 젤다 원리 EXP-Z01~06: 가림/부분 정보, 시각적 중력, 연쇄 발견, 곱셈 디자인, 세계 결과, 리듬. 예시: 교역 정거장으로 가다가 먼 섬광을 보고 소행성을 우회, 버려진 함선 발견, 생체 신호 확인, 구조/관찰/무시, 생명체 고향 단서. 정해진 퀘스트로 강제하지 않는다.
- 발견 후보: 버려진 함선, 우주 생명체, 고대 구조물, 숨은 정거장, 움직이는 함대, 미발견 행성. 정적인 장소와 실제 목적을 가진 동적 NPC를 구분.
- 알려진 지도 정보 vs 미발견 정확한 위치 비공개. 미발견→단서→탐지→직접 발견→조사→활용은 선택 가능한 예시. 소문은 지역/방향 중심, 정보 거래·센서·직업·동료 능력. 기록 영속화. 광물 정보 판매 후 채굴 시설/새 교역로 형성 예시. 센서/탐사 전문가/엔지니어/외교관/외계 동료별 다른 단서. 직업 없다고 기본 탐험 차단 금지.

## 3. 조우와 전투 (D12–16)
- 이동하는 상선 발견→센서로 소속·종류 확인→직접 접근→통신 요청→거래/외교/승선 시 상세 화면→동일 세계 위치/상태로 복귀. 추격·회피·전투는 항해 화면. 단순 근접만으로 강제 전환 금지. 상세 화면 시 시간/안전 미결.
- 상선이 해적에게 추격당할 때 구조/해적 지원/중재/양쪽 공격/무시/잔해 조사 가능성. NPC는 스스로 교전 및 이동. 상대도 플레이어에게 먼저 통신·도주·공격. 관계/화물/상태 반영.
- 기본 함포 자동은 교전한 적과 사거리/발사각에 한정. 수동 특수 무기 조준/발사 및 전술 능력은 직접 사용. 무기 예시 어뢰/레일건, 능력 예시 보호막/EMP/가속/수리 드론. 조작 충돌·조준 제스처·자동 발사 개시/취소는 프로토타입에서 확정. 중립 오발 방지.
- 예시 전투: 전함의 정면 화력 피하고 측면/후방으로 우회, 사거리와 발사각 확보, 엔진을 노린 특수 공격, 적의 미사일 회피, 전술 능력. 방향/약점은 함선별로 달라짐. 작은 함선도 위치 선정으로 강한 적에 대응할 여지.
- 보호막/선체/엔진/무장/센서 피해. 엔진 손상→추진력/회전 저하, 무장 손상→해당 공격 불능, 센서 손상→탐지/조준 저하. 눈으로 상태를 읽도록 추진 불꽃/파편/포신/보호막 굴절 등 사용. 수치와 피해 단계 미결.
- 타격감 후보: 발사 반동·섬광·소리→명중 충격파/파편→물리 반응→실제 기능 변화. 지상 hit-stop 수치 그대로 이식 금지. 기존 연구 자료는 참고, 실제 재미는 사용자 검증.
- 승리 후 격침/잔해, 항복·화물·정보·몸값 협상, 승선·백병전·탐사·탈취. 동료 일부가 승선하고 다른 승무원은 기함 보호하는 예시. 화물칸/기관실/함교/거주구역 후보. 확보 함선 수리/판매/편입. 수리비·연료·인력·평판으로 균형. 별도의 내부 시점/소유권 규칙 미결.
- 패배 후 세계 진행: 조난/응급수리, 항복/화물 손실, 포로/석방·탈출, 격침/탈출정, 동료 실종·구출. 예시: 해적에게 함선 잃음→탈출→작은 함선으로 재기→이전 함선을 다시 발견. 재기 경로 보장; 영구 사망/저장/손실 수치 미결.

## 4. 함대와 행성 탐험 (D17–19)
- 기함 직접 조종, AI 동행 호위, 별도 NPC 선장에게 교역/탐사/수송/군사 임무. 선장의 성격·능력·관계가 행동에 영향. 배신/충성도와 지휘 UI·규모·통신 범위 미결.
- 예시: 광물 발견→동료 채굴/탐사→수송→본거지 생산→교역→새 함선. 해적/고갈/전쟁에 영향을 받아 무조건 자동 수익 아님. 성장 후에도 직접 탐험 가능.
- 행성 탐험/지상 액션 쿼터뷰 확정. Tunic의 공간/숨은 길, Hades II의 쿼터뷰 액션 비교, Absolum의 명중 반응, Vanillaware의 미술 원리, Zelda 호기심. 벨트스크롤을 최종 시점으로 삼지 않음.
- 같은 공간에서 탐험→전투→탐험 연결은 제안. 나무 뒤 빛, 생물 울음, 구조물 일부가 자발적 이동 동기. 지형 자체가 탐험과 전투에 기여.
- D19 승인: 연결 탐험 지역과 일부 절차 생성 공간. 자연환경/정착지/유적/동굴/세력 거점/미개척 지역은 후보이며 모든 행성에 강제하지 않음. 예시: 마을에서 소문→숲 탐험→동굴 발견→재방문 시 구조와 기존 행동의 결과 유지. 시드 보존 및 생태/채집/NPC 활동에 따른 변화는 제안. [시각 도식](VISUAL_ATLAS.md#19-planet-regions-and-procedural-spaces).
- D20 승인: 일반 교전은 탐험 공간에서 실시간, 특수 전투 장소는 실제 입구/경계로 연결. 관찰·우회·교전·도주 가능. 예시: 영역을 지키는 생명체를 우회하거나 싸우고 유적 입구로 진입. 초식/포식/영역 방어 생물, 외계 NPC, 병사, 고대 기계의 서로 다른 목적/반응은 후보. 구체 AI와 전투 구역 진입/퇴장 미결. [설명 도식](visuals/20-ground-encounter.svg).
- D21 승인: 직접 이동/수동 공격+제한 조준·연계 보조. 자유 드래그/대상 터치/반복 터치·홀드/빠른 스와이프/맥락 능력은 후보. 한 손 이동·회피 충돌, 공격·대화·채집 터치 충돌, 중립 오발, 조준 보조의 의도 왜곡을 검증. [설명 도식](visuals/21-ground-input.svg).
- D22 승인: 공통 직접 이동·수동 공격·회피, 장비/직업에 따라 방어·반격·연계. 검+방패의 가드와 반격, 쌍검의 기동과 연계, 중량무기의 경직, 사격의 거리 유지, 드론의 공간 제어, 외계 기술의 교란, 지원형 협동은 예시. 모든 직업에 전용 가드/반격 버튼 강제 금지. 무기/직업 제한, 수치, 자원, 취소, 덱 연결 미결. [설명 도식](visuals/22-ground-combat-styles.svg).
- D23 승인: 공격 준비→가속→명중→피격 반응→회복과 실제 상황별 피드백. 경량 연타, 중량 단발, 원거리 반동/탄착은 리듬 후보. 빗맞음/방어/명중 구분, 공격 방향·적 상태에 맞는 경직/넉백, 히트스톱·카메라·음향·햅틱 동기화, 가독성·입력 반응성 유지. 공격 회복/취소와 입력 반응성은 구분. 수치·접근성 옵션 미결. [설명 도식](visuals/23-combat-impact-timing.svg).
- D24 승인: 근거리 개별 생명체 행동, 원거리 집단/환경/자원 상태 관리. 앱 종료 중 정지(D02), 세계 변화 보존(D19). 희귀 생명체와 동료 개별 정체성, 군집/포식/번식/이동/산업 영향은 후보. 예시: 채굴시설→서식지 변화→이동→자원·위험 변화. 생태 정밀도·개체 저장·멸종·재생·연산 예산 미결. [설명 도식](visuals/24-ecology-simulation.svg).
- D25 승인: 제한 공통 환경 속성과 도구의 조합(곱셈 디자인). 유적 앞 영역 생물을 정면 교전/소리 유인/은신/환경 도구로 대응하는 예시는 후보. 열·냉기·전기·전도성·무게·물리력·소리·진동·빛·가시성·물질·재질 후보; 속성/도구 목록, 파괴·저장, 예외·수치 미결. 도구 없이도 탐험할 수 있는 경로를 고려. [설명 도식](visuals/25-systemic-environment.svg).
- D26 승인: 일반 식물/광물 조각/작은 잔해 등은 짧은 상호작용 후보. 특수 광맥·위험 식물·기계 해체·희귀 생물 샘플 등에는 도구/동료/환경 대응과 직접 액션을 활용. 광석 균열→파편→획득 등의 실제 피드백(D23)과 환경 조합(D25) 연결. 자원 목록·도구·성공/실패·자동 위임은 미결. [도식](visuals/26-resource-gathering.svg).
- D27 승인: 일반 자원 수집/소지는 가볍게, 중요 자원은 보호·적재·귀환·수송 선택에 의미. 예시: 평범한 광물은 개인 가방, 대형 유물은 보호 용기 또는 수송 장비/동료 활용; 운반 경로의 위험과 보상 판단. 예시 장비/용기·제한 수치·손실 조건은 미확정. 죽거나 패배하면 전부 손실한다는 규칙 아님. 지속 세계(D19)와 재기 가능한 패배(D16) 유지. [도식](visuals/27-resource-transport.svg).
- D28 승인: 지형/함선에 맞는 착륙 장소 선택, 함선까지 직접 귀환 기본, 능력에 따른 조건부 호출/수송/회수. 정찰선의 좁은 착륙지, 수송선의 대형 화물, 환경 대응 장비, 동료 파일럿, 수송 드론은 후보. 착륙/호출 조건, 실제 위험·비용·시간·실패/회수 미결. 함선은 이동식 본거지이며 강제 원정 초기화 없음. [도식](visuals/28-landing-return.svg).
- D29 승인: 자원·정보·관계·세계 변화·새 탐험 기회 결합. 예시: 유적 발견→희귀 자원/고대 정보/생물 교감→제작·새 항성계 단서·영입→새 탐험 가능성. 모든 발견에 동일 보상 강제 금지. D11/D19/D24/D25/D26~28 유지. [설명 도식](visuals/29-discovery-reward-loop.svg).
- STEP 4 핵심 방향(D18–D29) 승인 완료. 실제 조작, 지형·생태·자원·화물·착륙·보상 콘텐츠와 수치, 레벨 설계, 테스트는 남아 있음.

## 5. 캐릭터 생성·직업·성장
- D30 승인: 상황 기반 성향 질문→초기 설정 추천→영향 확인→직접 수정→시작. 예시 질문: 조난 신호 대응(구조/분석/준비/협력), 행성에서 원하는 활동(생명체/유적/자원·기술/교역), 함선의 의미(여행/탐사/기술/생활). 예시 3문항·4성향 및 단순 응답 집계는 확정 알고리즘 아님. 장래 직업·성향 변경을 강제 제한하지 않음. [도식](visuals/30-character-creation.svg).
- D31 승인: 질문 결과로 배경·초기 능력·직업·함선을 하나의 시작 프로필로 추천하되 각각 확인·수정 가능. 예시: 민간 수송선/파일럿/고속선, 행성 조사단/수색대원/탐사선, 정거장 정비공/엔지니어/작업선, 민간 구조대/의무관, 성간 상단/외교관. 이 배경과 함선·능력 조합은 확정 목록/강제 매핑 아님. [도식](visuals/31-starting-profile.svg).
- D32 승인: 3종 기본 함선+제한적 초기 장비 선택. 고속선/탐사선/작업선 예시, 탐지 장비/추가 적재함/기동 보조 예시. 함선 기본 장단점 및 공통 핵심 활동 유지. D31 추천 강제 금지, 후속 함선 교체·개조 가능 방향. 실제 장비·능력·비용 미결. [도식](visuals/32-starting-ships-proposal.svg).
- D33 승인: 초기 직업은 출발점, 교차 기술 습득 및 전문화 가능. 파일럿+탐색→정찰 항해자, 엔지니어+교섭→기술 상인, 의무관+생태 지식→생물 구조 전문가 예시. 모든 활동을 직업으로 제한하지 않음. 실제 직업/해금/전문화 제한·동료 관계·재설정 규칙 미결. [도식](visuals/33-cross-profession-growth.svg).
- D34 승인: 실제 관련 활동→숙련→의미 있는 기술 선택. 비전투 성장과 반복 노가다 방지 방향. 심층 탐지/생태 분석/고대 기술 판독은 예시; 교관/연구/훈련 등 습득 경로와 조건·수치 미결. [도식](visuals/34-activity-skill-growth.svg).
- D35 승인: 폭넓은 기술 습득 및 깊은 전문화 투자·기회비용. 전문 파일럿/탐험형 엔지니어/다재다능한 선장 비교, 파일럿+정비 동료+환경 탐지 외계 생물은 예시. 모든 최고 숙련 가능 여부와 구체 상한·투자·재설정 규칙 미결. [도식](visuals/35-specialization-profiles.svg).
- D36 미결: A 수치 보너스 / B 새 행동·해결 방법 / C 기초 숙련은 수치·안정성, 핵심 기술은 새 행동·해결 경로(추천). 구체 능력 목록·수치·중첩·조작 미승인.

## 승인 전 검증 원칙
실제 화면/제스처/행동-결과의 시나리오를 먼저 보여준다. 예시나 비교 이미지가 승인된 기능/픽셀/정량 목표가 되지 않는다. 360×640 / 393×852 세로 화면은 테스트 후보. 60~120초 항해에서 자발적 우회와 단서 발견, 90초 내 입력 발견, 전투에서 피격·회피·기능 손상 이해를 실사용자가 검증. 코드/CI/정적 이미지와 플레이 감각은 별개. 첫 10분 스토리보드 및 인게임 콘셉트 이후 통합 승인.
