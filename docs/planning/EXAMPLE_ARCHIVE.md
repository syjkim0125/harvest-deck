[도식](visuals/40-alien-bonding-proposal.svg) · [결정](DECISION_VISUAL_INDEX.md#d40).

D40 상세 예시: 호기심 많은 소형 생명체(거리 유지·환경 탐험·친숙해지기, 위험하지 않으면 스스로 접근), 부상 생명체(구조·치료·보호, 회복 후 동행 또는 서식지 복귀), 경계심 높은 무리 생물(생태 관찰·습성 이해·안전 환경, 동행하지 않을 수 있음). 발견→이해→교감→관계 형성→자발적 동행 또는 독립 생활은 설명용 흐름, 고정 절차 아님. 자체 도식은 최종 생물 아트 아님.

## D41 동료 관계와 신뢰 구조 — C 승인

A 단일 호감도 중심 / B 성격·욕구·관계의 상세 시뮬레이션 / C 핵심 관계 상태+개별 성격·목표·경험에 따른 변화(추천). 예시: 신중한 정비공은 약속 이행과 안정적인 생활을 중요하게 여기고, 모험적인 파일럿은 새로운 탐험과 자율성을 중요하게 여김. 같은 위험 항해라도 다르게 반응. 소리에 민감한 외계 생물은 시끄러운 환경에서 불안해할 수 있고, 안전한 공간에서 회복. 핵심 상태 후보: 신뢰(선장과 관계), 생활 만족/안정(현재 환경), 개인 목표와 경험(사건 및 맥락). 생물의 표현은 친숙함·안정감 등으로 구분 가능. 모든 상태를 별도 게이지로 만들거나 지속 관리 강제하지 않고 변화 이유를 보여주는 제안. 이탈/갈등/회복의 조건·상태 개수·수치·UI는 별도 미결. ## D44 동료의 성장과 전문화 — C 승인
<a id="example-d44"></a>
A 동료별 고정 능력 / B 플레이어와 동일한 성장 체계 / C 실제 활동 기반 성장 + NPC 전문화·외계 생명체의 종별 능력 및 교감 성장(추천). 일반 NPC 정비공은 실제 정비·연구 활동으로 숙련되고, 고대 기계 복구 등 전문 기술을 배울 수 있음. 플레이어와 같은 성장 원리를 공유하되 매번 기술 선택 화면을 강제하지 않고, 동료 성격·목표와 선장의 역할/훈련 방향이 성장 선택에 관여하는 후보. 외계 생명체는 종별 고유 능력의 활용·환경 경험·교감으로 탐색 능력의 정밀도 및 협동 가능 행동을 발전시키는 후보(진동 감지 생물: 미세 진동 감지→숨은 자원 탐지·위험 신호). 다른 종처럼 임의 변화/진화하거나 모든 인간 직업을 수행할 수 있다고 확정하지 않음. 동료의 자율 성장·훈련·전문 기술 선택 개입 정도, 종별 상한·진화/형태 변화·성장 수치·UI는 미결. [도식](visuals/44-companion-growth-proposal.svg) · [결정](DECISION_VISUAL_INDEX.md#d44).

D44 대화 상세 예시: 정비공(기본 함선 수리/정비 → 실제 수리·제작·연구로 숙련 → 고대 기계 복구·함선 개조·자동화 설비 전문화); 진동 감지 생명체(미세 진동 감지 → 경험으로 숨은 자원/공간 탐색 → 교감으로 위험 감지 및 신호 전달). 동일 개체의 감지 범위 확대 원형 도식은 설명용, 수치/형태 확정 아님. 실제 활동 기반 성장과 새로운 협동 행동 중심. 생물 진화/외형 변화 및 성장 제한은 미결.

## D45 동료의 부상·갈등·이탈·손실 — C 승인
<a id="example-d45"></a>
A 동료의 영구 손실 없음 / B 위험과 갈등에 따른 영구 손실 중심 / C 부상·갈등·일시적 이별과 회복 기회 중심 + 조건부 영구 이탈·손실(추천). 사례: 지상에서 부상한 정비공을 치료·휴식시켜 복귀, 함선 사고 후 실종된 파일럿을 수색해 구조, 반복 갈등으로 떠난 NPC는 세계에 계속 존재하며 조건에 따라 관계 회복·재회 가능, 생태 환경에 적응하지 못한 생명체는 서식지 복귀 가능. 심각한 위험이나 돌이킬 수 없는 사건에서는 영구 손실도 후보이나 죽음의 허용/제한과 세부 발생 조건은 미결. 회복 경로와 위험을 충분히 읽을 수 있도록 하고, 사소한 반복 실수로 소중한 동료를 예고 없이 잃거나 관계 관리 노가다를 강제하지 않는 제안. 자동 부활·죽음 확정 규칙 아님. D16 세계 지속 및 재기, D38–44 정체성·자발적 관계·배치·성장과 연결. [도식](visuals/45-companion-loss-recovery-proposal.svg) · [결정](DECISION_VISUAL_INDEX.md#d45).

D45 상세 예시: 부상 정비공→치료·휴식·복귀, 실종 파일럿→조난 신호·NPC 정보로 수색/구조, 갈등으로 떠난 NPC→다른 정거장 재회 가능, 환경 부적응 생물→서식지 복귀(적대화 필수 아님). 함선 전투 패배→부상/실종/포로→치료·휴식/추적·구조/협상·구출→재회 기회(성공 보장 없음). 확정 분기·사망 규칙 아님.

## D46 함선 내부 경험과 운영 방식 — C 승인

## D63 카드 소유권과 동료·장비 상실의 영향 — C 승인
<a id="example-d63"></a>
A 모든 카드 영구 소유·조건 없이 사용 / B 카드가 동료·장비에 완전 귀속되어 상실 시 소멸 / C 습득한 지식은 보존 + 실제 발동 조건·고유 능력은 소유자와 연결(추천). 학습·연구·기록으로 획득한 재현 가능한 카드 지식은 유지하되, 실제 발동은 필요한 장비·시설·동료·환경 조건을 충족할 때만 가능하도록 한다. 특정 동료·생명체 개인의 고유 능력 또는 관계 기반 합동 전술은 해당 존재·관계에 연결하며 이탈·부상·영구 손실 시 일시 비활성 또는 이용 불가가 될 수 있다. 유사 장비 복구·교체나 다른 동료의 독립적인 훈련으로 재현 가능한 능력은 다시 활성화 후보; 다른 개체로 고유 관계·개인 능력을 자동 복제하지 않는다. 카드 기록과 장착 가능 여부를 명확히 구분하고, 조건 미충족 카드는 활성 손패를 막지 않도록 처리한다. D43–45/D58/D62 유지. 지식 보존 매체·카드 귀속 유형·사용 조건·상실·재학습·대체·동료 전수·덱 편집·UI 미결. 실제 영구 상실 조건은 기존 승인 범위를 넘지 않으며 보유 기록이 모든 능력의 영구 사용을 보장하지 않는다. 예시: 연구로 배운 EMP 전술은 장비 손실 시 지식은 남지만 발동 불가; 호환 장비 확보 후 다시 활성 후보. 동료 전용 합동 전술은 부상 중 비활성, 회복 후 복귀 후보. 외계 생명체 고유 공명은 해당 생명체와의 교감 및 동행 조건을 요구하며 다른 개체로 자동 복제되지 않는다. ## D64 카드 성장과 강화 방식 — C 승인
<a id="example-d64"></a>
A 선형 레벨·수치 강화 / B 카드 자체 강화 없이 새 카드 수집 / C 실제 활동 기반 숙련·연구 + 선택형 특화 강화(추천). 카드의 성장 기회는 의미 있는 실제 활동·훈련·연구·장비 개선과 연결하고, 단순 반복 사용이나 카드 중복 수집을 필수로 하지 않는다. 제한된 선택형 특화로 같은 카드가 서로 다른 역할에 적합한 효과·비용·범위·연계 방식으로 발전하는 방향을 검토한다. 모든 강화가 일방적 수치 상승이 되지 않게 기회비용과 역할 차이를 설계하며 기본 카드도 가치 유지. 숙련과 연구는 전술/운용 및 귀속 조건에 맞게 적용하고 D63 고유 능력 자동 복제 금지. 성장 단계·분기 개수·되돌리기·실물 비용·숙련 판정·중복·희귀도·저장 방식·UI 미결. 카드 과다·최적 단일 분기·반복 파밍·전력 인플레이션을 플레이 검증. 예시: EMP 방출 기본(근거리 교란)→정밀 교란(단일 대상 효과에 특화) 또는 연쇄 교란(다수 대상, 비용 증가) 또는 절전형(효과 범위 축소, 비용 감소). 운용 유물 분석→신속 분석(시간 절약, 정보 깊이 제한) 또는 심층 분석(추가 시간·재료, 새로운 단서 기회). 특화는 수치·보상·획득·분기 변경 규칙 미확정. ## D65 덱 구성과 편집 시점 — C 승인
<a id="example-d65"></a>
A 언제 어디서나 자유 편집 / B 안전 거점에서만 편집 / C 안전한 상황에서 자유 구성 + 위험 중 편집 제한·조건부 대응(추천). 안전한 함선·거점·비교전 상태 등 준비 가능한 상황에서 소유한 적격 카드로 전술/운용 덱을 자유롭게 구성하는 방향. 준비된 여러 프리셋은 상황 전환 시 편리하게 선택할 수 있도록 검토하되, 진행 중 교전·위험 탐험·생산/거래 단계에서 무제한 덱 교체·카드 추가로 손패 순환과 비용을 우회하지 못하게 한다. 위험 중에는 이미 승인된 제한적 손패 교체(D56), 장비·동료 상실에 따른 적격성 조정(D63), 제한된 긴급 대응을 검토. 위험 해제 후 재편집, 거점별 덱/위임 정책(D61) 변경은 기존 작업 자원·결과를 초기화하지 않는다. 카드 구성 변경은 지식 소유나 특화 해금 자체를 삭제하지 않는다. 정확한 안전 판정·편집 비용·프리셋 수·전환 쿨다운·손패 및 드로우 상태·동료 위임 범위·덱 크기·중복·UI 미결. 위험 회피로 무한 리셋하는 악용과 불필요한 귀환 강제 방지 검증. 예시: 행성 착륙 전 안전한 함선에서 탐험 덱을 편집, 교전 중에는 기존 손패 교체만 허용, 교전 종료 후 준비 가능한 상태에서 전술 덱 변경. 위임 상점에서 운영 정책 변경은 진행 중 판매/재고를 되감지 않는다. 프리셋은 후보이며 수치·제한 미확정. [도식](visuals/65-deck-editing-proposal.svg).

## D66 덱 크기·중복 카드·구성 제한 — C 승인
<a id="example-d66"></a>
A 자유로운 덱 크기·중복 / B 고정 덱 크기·모든 카드 1장 제한 / C 역할별 제한 범위 + 제한적 중복·맥락 및 장비 조건(추천). 전술/운용 덱의 역할과 실제 플레이 리듬에 맞는 제한된 덱 크기 범위를 검토한다. 일정한 최소 크기로 지나치게 짧은 반복 순환을 방지하고 상한으로 지나치게 큰 덱 및 관리 부담을 줄인다. 일반 카드의 제한적 중복은 빌드 차이를 만들 때 허용 후보이며 고유 개인/관계 능력과 실제 장비·동료 조건, 특화 계열 중복 제한을 구분한다. 카드 수에 따라 무한 드로우·에너지 회복·작업 보너스 반복을 우회할 수 없게 한다. 카드 획득과 중복 장착 허용은 별개이며 동일 카드 반복 수집을 강제하지 않는다. 기본 카드와 적격 카드 부족 시 유효한 초기 덱/안전한 대안 제공 후보; 기본 이동·공격·회피·경제 활동은 카드와 독립. D54–65 유지. 정확한 전술/운용 덱 크기, 손패 크기, 같은 계열·특화·고유 카드 제한, 장비·동료 조건, 컨텍스트 필터 후 최소 덱 유지, 프리셋 및 위임 정책, 카드 추가/제거·전환 상태, UI 미결. 모바일 실기기에서 순환 예측성·선택 다양성·가독성 비교 검증. 예시: 설명용으로 6~10장 덱 범위와 최대 일반 카드 2장/개인 고유 카드 1장을 비교하며 3장 손패를 가정한다(실제 수치 아님). 6장 덱은 핵심 카드 재등장 예측성이 높고, 10장 덱은 상황 대응 다양성이 높다. 일반 카드 EMP 중복 2장은 후보, 고유 합동 전술 중복은 제한 후보. 전술/운용 덱의 실제 크기 및 중복 규칙은 별도 검증. ## D67 전술 덱과 운용 덱의 교차 시너지 — C 승인
<a id="example-d67"></a>
A 두 덱 독립·공유 성장만 / B 카드끼리 직접 연쇄·보너스 연결 / C 실제 세계의 결과를 매개로 한 교차 시너지 + 제한적 명시적 연계(추천). D55 공유 성장·교차 시너지를 구체화한다. 전술과 운용 덱은 각각 독립적인 플레이 가치를 유지하되 실제 전투·탐험·연구·제작·교역의 결과(실물 재료·정보·장비·관계·세계 상태)가 상대 덱의 획득/사용/특화 기회와 상황을 변화시키도록 검토한다. 일부 명시적 연결 카드는 그 결과와 조건에 기반한 제한적 보너스/새 선택을 제공할 수 있으나 단순 양쪽 카드 발동만으로 무한 연쇄·자동 자원 생성·곱연산 증폭·강제 왕복을 만들지 않는다. 전투를 하지 않는 탐험가/상인 및 운용을 위임한 전투 전문가도 각각 독립 성장 경로를 확보한다. D55/D58–64 유지. 카드 예시는 후보이며 결과 매개 데이터·보너스 한도·동료 위임·재사용 조건·비용·귀속·UI 미결. 실물 비용/물류·선택 기회가 유지되는지, 양쪽 활동 강제나 한쪽 우월 빌드 여부를 검증. 예시: 탐험에서 회수한 외계 중력 유물→운용 유물 분석/실제 연구→호환 장비 제작→전술 중력 제어 활용→교전 결과 회수 재료→운용 제작/판매 기회. 비전투 탐험가는 유물 연구·거래로 성장 가능, 전투 전문가는 구매·동료 위임으로 연구/제작 접근 가능. 일부 연결 카드 후보 약점 기록(실제 탐지 데이터 활용), 잔해 분석(회수된 잔해에서 연구 기회). 효과는 실물 결과/조건에 의존하며 무한 순환 보상 없음. ## D68 은하계 경제와 실제 자원 순환의 범위 — C 승인
<a id="example-d68"></a>
A 지역별 고정 가격·단순 재고 / B 모든 NPC·상품의 완전한 개별 경제 시뮬레이션 / C 실제 생산·수요·재고·물류 기반 지역 경제 + 거리별 시뮬레이션 추상화(추천). 지역/정착지/세력의 실제 생산·소비·재고·수요 및 물류가 가격과 상품 가용성에 영향을 주는 경제를 검토한다. 가까운 활동 지역은 개별 거래·화물·시설·NPC 활동을 구체적으로 처리하고 먼 지역은 집계된 생산/소비/수송 단위로 추상화할 수 있다. 추상화는 이미 존재하는 물자·소유권·운송 시간·손실·거래 결과의 일관성을 보존하고 상세 전환 시 재고를 복제하거나 초기화하지 않는다. NPC의 경제 활동은 플레이 중 자율 진행하며 앱 종료 중 세계 정지(D02). 실제 물류·자율 거점 운영 D50–53 및 실제 비용 D61/D67 유지. 가격 공식, 상품 범주, 생산/소비 주기, 자원 생성/소멸, 화폐·상인 자본, 운송 단위, 거리/중요도 기준, 데이터 일관성, 시뮬레이션 성능·UI 미결. 플레이어가 모든 부족을 해결해야 하는 의무나 모든 NPC의 개별 소비를 실시간 처리하는 부담을 지양. 시장 개입의 영향과 회복 가능성·독점·무위험 반복 차익·모바일 성능 검증. 예시: 광산 정착지에서 광석 생산→화물선 실제 운송→공업 정착지에서 부품 생산→소비 정착지에서 판매. 운송 중단은 수입지의 재고 감소와 가격 상승 압력으로 이어지며 기존 재고·대체 공급·NPC의 운송 복구로 완화될 수 있다. 먼 지역은 집계 흐름, 가까운 지역은 개별 화물선·시설·거래. 가격과 수량은 미확정. [도식](visuals/68-economy-simulation-proposal.svg).

## D69 자원 분류와 생산·소비 단계 — 미승인 제안
<a id="example-d69"></a>
A 소수의 범용 재료로 단순화 / B 세분화된 원료·부품·제품의 상세 생산망 / C 직관적인 핵심 자원군 + 지역·용도별 특수 자원 + 필요한 만큼의 가공 단계(추천). 초기에는 이해하기 쉬운 핵심 자원군(원자재·생체 자원·에너지/연료·가공 재료/부품·완제품/소비재 등 후보)을 제공하고 지역의 지질·생태·산업·기술에 따른 특수 자원으로 탐험·교역·연구 동기를 만든다. 자원별 실제 용도와 생산/소비 주체를 정의하며, 의미 있는 경우에만 원료→가공→제품 단계와 대체 경로를 둔다. 상품과 장비, 기술 정보/설계도, 관계 데이터는 동일한 물리 자원으로 취급하지 않는다. 원료는 실제 채집·생산·거래·회수로 확보하고 가공·소비·손실 시 재고 변화를 보존한다. 생태·희귀 자원의 유한성/재생·환경 영향·대체재·품질·등급·시설 및 생산 시간·레시피 깊이·NPC 수요·재고 단위·운송·UI는 미결. D26–29/D50–53/D61/D67–68 유지. 모든 자원에 의무 가공 단계를 부여하거나 잡다한 재료/중간품 수집 노가다를 만들지 않는다. 핵심 자원군 명칭/종류/개수는 예시이며 모바일 가독성·실제 수요·경제 안정성 검증 필요. 예시: 금속 광석→합금→함선 부품→수리/장비 제작; 생체 섬유→의료 소재→치료 키트→치료/판매; 희귀 중력 결정→특수 연구·호환 장비, 일반 재료와 차별화. 수치·레시피·자원군 이름 미확정. [도식](visuals/69-resource-chain-proposal.svg).
