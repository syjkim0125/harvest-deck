[도식](visuals/40-alien-bonding-proposal.svg) · [결정](DECISION_VISUAL_INDEX.md#d40).

D40 상세 예시: 호기심 많은 소형 생명체(거리 유지·환경 탐험·친숙해지기, 위험하지 않으면 스스로 접근), 부상 생명체(구조·치료·보호, 회복 후 동행 또는 서식지 복귀), 경계심 높은 무리 생물(생태 관찰·습성 이해·안전 환경, 동행하지 않을 수 있음). 발견→이해→교감→관계 형성→자발적 동행 또는 독립 생활은 설명용 흐름, 고정 절차 아님. 자체 도식은 최종 생물 아트 아님.

## D41 동료 관계와 신뢰 구조 — C 승인

A 단일 호감도 중심 / B 성격·욕구·관계의 상세 시뮬레이션 / C 핵심 관계 상태+개별 성격·목표·경험에 따른 변화(추천). 예시: 신중한 정비공은 약속 이행과 안정적인 생활을 중요하게 여기고, 모험적인 파일럿은 새로운 탐험과 자율성을 중요하게 여김. 같은 위험 항해라도 다르게 반응. 소리에 민감한 외계 생물은 시끄러운 환경에서 불안해할 수 있고, 안전한 공간에서 회복. 핵심 상태 후보: 신뢰(선장과 관계), 생활 만족/안정(현재 환경), 개인 목표와 경험(사건 및 맥락). 생물의 표현은 친숙함·안정감 등으로 구분 가능. 모든 상태를 별도 게이지로 만들거나 지속 관리 강제하지 않고 변화 이유를 보여주는 제안. 이탈/갈등/회복의 조건·상태 개수·수치·UI는 별도 미결. ## D44 동료의 성장과 전문화 — C 승인
<a id="example-d44"></a>
A 동료별 고정 능력 / B 플레이어와 동일한 성장 체계 / C 실제 활동 기반 성장 + NPC 전문화·외계 생명체의 종별 능력 및 교감 성장(추천). 일반 NPC 정비공은 실제 정비·연구 활동으로 숙련되고, 고대 기계 복구 등 전문 기술을 배울 수 있음. 플레이어와 같은 성장 원리를 공유하되 매번 기술 선택 화면을 강제하지 않고, 동료 성격·목표와 선장의 역할/훈련 방향이 성장 선택에 관여하는 후보. 외계 생명체는 종별 고유 능력의 활용·환경 경험·교감으로 탐색 능력의 정밀도 및 협동 가능 행동을 발전시키는 후보(진동 감지 생물: 미세 진동 감지→숨은 자원 탐지·위험 신호). 다른 종처럼 임의 변화/진화하거나 모든 인간 직업을 수행할 수 있다고 확정하지 않음. 동료의 자율 성장·훈련·전문 기술 선택 개입 정도, 종별 상한·진화/형태 변화·성장 수치·UI는 미결. [도식](visuals/44-companion-growth-proposal.svg) · [결정](DECISION_VISUAL_INDEX.md#d44).

D44 대화 상세 예시: 정비공(기본 함선 수리/정비 → 실제 수리·제작·연구로 숙련 → 고대 기계 복구·함선 개조·자동화 설비 전문화); 진동 감지 생명체(미세 진동 감지 → 경험으로 숨은 자원/공간 탐색 → 교감으로 위험 감지 및 신호 전달). 동일 개체의 감지 범위 확대 원형 도식은 설명용, 수치/형태 확정 아님. 실제 활동 기반 성장과 새로운 협동 행동 중심. 생물 진화/외형 변화 및 성장 제한은 미결.

## D45 동료의 부상·갈등·이탈·손실 — C 승인
<a id="example-d45"></a>
A 동료의 영구 손실 없음 / B 위험과 갈등에 따른 영구 손실 중심 / C 부상·갈등·일시적 이별과 회복 기회 중심 + 조건부 영구 이탈·손실(추천). 사례: 지상에서 부상한 정비공을 치료·휴식시켜 복귀, 함선 사고 후 실종된 파일럿을 수색해 구조, 반복 갈등으로 떠난 NPC는 세계에 계속 존재하며 조건에 따라 관계 회복·재회 가능, 생태 환경에 적응하지 못한 생명체는 서식지 복귀 가능. 심각한 위험이나 돌이킬 수 없는 사건에서는 영구 손실도 후보이나 죽음의 허용/제한과 세부 발생 조건은 미결. 회복 경로와 위험을 충분히 읽을 수 있도록 하고, 사소한 반복 실수로 소중한 동료를 예고 없이 잃거나 관계 관리 노가다를 강제하지 않는 제안. 자동 부활·죽음 확정 규칙 아님. D16 세계 지속 및 재기, D38–44 정체성·자발적 관계·배치·성장과 연결. [도식](visuals/45-companion-loss-recovery-proposal.svg) · [결정](DECISION_VISUAL_INDEX.md#d45).

D45 상세 예시: 부상 정비공→치료·휴식·복귀, 실종 파일럿→조난 신호·NPC 정보로 수색/구조, 갈등으로 떠난 NPC→다른 정거장 재회 가능, 환경 부적응 생물→서식지 복귀(적대화 필수 아님). 함선 전투 패배→부상/실종/포로→치료·휴식/추적·구조/협상·구출→재회 기회(성공 보장 없음). 확정 분기·사망 규칙 아님.

## D46 함선 내부 경험과 운영 방식 — C 승인

## D53 거점 방어·분쟁과 손실 방식 — C 승인
<a id="example-d53"></a>
A 거점은 안전하며 공격받지 않음 / B 실시간 전면 공격·파괴·점령 / C 위험과 소유권에 따른 분쟁 + 자율 방어 + 예고·대응·복구 기회(추천). 거점 위험은 입지·소유권·세력 관계·활동·주변 사건에 따라 달라진다. 평시 경비·방어는 배치 인력·시설·호위에 위임하고 의미 있는 위협은 정보·경고 및 대응 기회를 제공한다. 협상·지원 요청·호위/증원·직접 방어·철수·복구 등 복수 경로를 제안한다. 손상·약탈·점령·상실은 조건부 후보이며 모든 공격에 영구 손실을 강제하지 않는다. 안전 지역의 절대 무적 여부, 경고 조건·시간, 피해·점령·소유권·보험·외교·AI·UI 미결. 앱 종료 중 진행하지 않음(D02). 예시: 안정된 정거장 임대 상점은 현지 경비와 계약에 의존하고 국경 채굴 전초기지는 경비·호위 및 위험 정보가 중요하다. 주변 해적 활동 증가→위협 보고→현지 경비/호위, 교섭·증원·직접 방어 또는 철수 선택→안전·부분 손상·복구·조건부 상실의 결과 후보. 모든 위협을 즉시 강제 전투로 전환하지 않으며 동일 플레이 중 세계와 물류 상태에 연결한다. [도식](visuals/53-outpost-defense-proposal.svg).

## D54 실시간 플레이와 덱빌딩의 관계 — 미승인 제안
<a id="example-d54"></a>
A 카드 선택이 주요 행동을 결정 / B 덱은 사전 구성한 지속 효과 중심 / C 직접 조작 중심 + 맥락 전술 능력·운용 시너지 덱(추천). 이동·기본 공격·회피·상호작용을 덱으로 대체하지 않는다. 전술 덱으로 무기·장비·동료 능력과 상황별 능력·연계를 구성하고, 운용 덱으로 탐험 준비·연구·생산·교역·동료 시너지를 연결하는 방향을 비교한다. 카드 선택을 모든 행동에 강제하지 않는다. 전술/운용 덱의 분리 여부, 드로우·손패·발동 입력·쿨다운·자원·획득·교체·밸런스는 미결. D13/D21–23/D25/D29/D36–37/D42/D48–52 유지. 예시: 직접 기동·기본 무기 교전 중 센서 동료의 약점 탐지 능력과 EMP 장비 전술을 조합, 이후 정거장에서 회수 자원을 연구/제작하고 운용 덱을 교역·탐험 목적에 맞춰 구성. 카드의 실제 효과·입력·드로우·덱 분리는 미결.
