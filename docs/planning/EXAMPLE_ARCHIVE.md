## D40 외계 생명체 교감·영입 방식 — C 승인
<a id="example-d40"></a>
A 포획·수집 중심 / B 구조·교감 중심 / C 생명체의 생태·개체 특성에 따른 다양한 교감과 자발적 동행(추천). 예시: 호기심 많은 진동 감지 생물은 거리를 두고 접근하며 친숙해진 뒤 따라올 수 있음; 부상당한 소형 생물은 치료 후 서식지로 돌아가거나 동행할 수 있음; 경계심 높은 무리 생물은 습성과 안전한 환경을 이해해야 접근 가능하며 일부는 동행하지 않을 수 있음. 관찰→습성/상황에 적합한 행동→신뢰/교감 변화→동행 여부. 고정 순서·무조건 영입·반복 먹이 주기 강제 아님. 포획 허용 여부, 종별 영입 가능 범위, 구체 조건·수치·UI는 미결. [도식](visuals/40-alien-bonding-proposal.svg) · [결정](DECISION_VISUAL_INDEX.md#d40).

D40 상세 예시: 호기심 많은 소형 생명체(거리 유지·환경 탐험·친숙해지기, 위험하지 않으면 스스로 접근), 부상 생명체(구조·치료·보호, 회복 후 동행 또는 서식지 복귀), 경계심 높은 무리 생물(생태 관찰·습성 이해·안전 환경, 동행하지 않을 수 있음). 발견→이해→교감→관계 형성→자발적 동행 또는 독립 생활은 설명용 흐름, 고정 절차 아님. 자체 도식은 최종 생물 아트 아님.

## D41 동료 관계와 신뢰 구조 — 미승인 제안
<a id="example-d41"></a>
A 단일 호감도 중심 / B 성격·욕구·관계의 상세 시뮬레이션 / C 핵심 관계 상태+개별 성격·목표·경험에 따른 변화(추천). 예시: 신중한 정비공은 약속 이행과 안정적인 생활을 중요하게 여기고, 모험적인 파일럿은 새로운 탐험과 자율성을 중요하게 여김. 같은 위험 항해라도 다르게 반응. 소리에 민감한 외계 생물은 시끄러운 환경에서 불안해할 수 있고, 안전한 공간에서 회복. 핵심 상태 후보: 신뢰(선장과 관계), 생활 만족/안정(현재 환경), 개인 목표와 경험(사건 및 맥락). 생물의 표현은 친숙함·안정감 등으로 구분 가능. 모든 상태를 별도 게이지로 만들거나 지속 관리 강제하지 않고 변화 이유를 보여주는 제안. 이탈/갈등/회복의 조건·상태 개수·수치·UI는 별도 미결.
