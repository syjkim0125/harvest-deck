# 대화 예시 상세 보존 — D19–D34
2026-11-27 · 확인 가능한 대화 내용을 재구성한 상세 보존본. 대화의 모든 문장 축어록이나 원본 화면 캡처가 아니다. 승인된 결정은 GDD, 예시·대안·수치·UI는 미승인. D01–D18은 [결정 이력](DECISION_HISTORY.md)의 기존 상세 재구성 및 [시각 도식](VISUAL_ATLAS.md), [레퍼런스](REFERENCES.md) 보존. 이전 대화 검색에서 추가 축어록/이미지 원본을 확보하지 못함.

## D19 행성 공간
A 전체 오픈월드(자유도·제작 부담), B 연결 지역(고유 장소 재방문), C 절차 원정 던전(반복 다양성·지속 세계 약화), D 연결 지역+일부 절차 공간. 예시 지역: 자연환경(탐험/채집/관찰/사냥), 정착지(교류/교역/영입), 고대 유적(역사/기술/비밀), 동굴(위험/희귀 자원), 세력 거점(외교/잠입/전투), 미개척지(발견/전초기지). 모든 행성에 이 목록 강제하지 않음. 첫 방문 외계 마을→희귀 생물 소문→숲→동굴→고대 문명 흔적; 재방문 시 마을/발견 기록 및 변화 유지. 생성 공간 시드 저장, 생물/NPC/채굴에 따른 변화는 후보. [도식](visuals/19-planet-regions-procedural.svg).

## D20 전투 연결
A 별도 전투 모드, B 전부 동일 공간, C 동일 공간+특수 구역. 유적 입구 앞 영역 생물을 관찰, 우회, 교전, 유인, 지형을 이용해 도주, 보스 구역 자발적 진입. 초식 생물(먹이/무리→경계/도주), 포식자(사냥/영역→추격), 영역 방어 생물(둥지/새끼→경고/공격), 외계 NPC(교역/생활→교류/협상), 세력 병사(순찰/경비→검문/추격), 고대 기계(시설 유지/방어→침입 감지). [도식](visuals/20-ground-encounter.svg).

## D21 조작
A 전부 수동, B 자동 기본 공격, C 직접 이동·수동 공격+조준/연계 보조. 입력 후보: 화면 자유 드래그 이동, 적/공격 대상 터치, 반복 터치/홀드 연속 공격, 빠른 스와이프 회피, 최소 맥락 버튼/제스처 특수 능력, 제한 조준 보조, 접근 후 대상 터치 채집/대화. 이동/회피 및 공격/상호작용 충돌 검증. [도식](visuals/21-ground-input.svg).

## D22 전투 스타일
A 공격·회피 중심, B 가드/반격까지 공통 필수, C 공통 공격/회피+장비/직업별 대응. 검+방패(방어·반격), 쌍검(빠른 회피/연계), 중량 무기(묵직한 일격·자세 무너뜨리기), 원거리(거리/정밀 조준/엄폐), 드론(설치·지원·공간 제어), 외계 기술(에너지 조작/교란). 지원형(회복·보호·협동) 추가 후보. 공격 예고→대응(회피/방어)→반격 기회. 모든 직업에 가드 버튼 강제 금지, 덱 행동/조합 확장 후보. [도식](visuals/22-ground-combat-styles.svg).

## D23 타격감
A 빠른 연타, B 묵직한 한 방, C 무기·상황별 차등/입력 반응성. 준비→가속→접촉→히트스톱→피격 반응→회복. 가벼운 연타의 짧은 반응, 중량 무기의 예고와 큰 충격, 원거리 발사 반동/탄착. 넉백·경직·카메라·음향·햅틱 동기화. 빗맞음/막힘/명중의 차이와 적 크기/방어/피해 차이. 그래프는 정성적 예시, 실제 프레임·강도 아님. [도식](visuals/23-combat-impact-timing.svg).

## D24 생태계
A 고정 배치/재생성, B 모든 개체 정밀 시뮬레이션, C 근거리 개체 행동+먼 지역 집단 상태. 군집/먹이사슬/둥지·번식/환경 이동 예시. 숲에서 포식 장면 발견→채굴 시설 증가→서식지 감소→생물 이동→재방문 변화. 환경/기후, 식물/자원, 초식·포식, NPC/산업 연결. 주변 개체 행동, 같은 행성의 먼 지역 개체군/먹이/서식지, 다른 행성의 필요 수준 집단 상태; 희귀 생물 기록, 영입 동료 독립 정체성 후보. 앱 종료 시간 정지. [도식](visuals/24-ecology-simulation.svg).

## D25 환경
A 지정 상호작용, B 전면 물리/화학, C 제한 공통 속성+도구. 열/냉기(연소·융해·생물 반응), 전기/전도성(회로·기계·교란), 무게/물리력(장애물·압력 장치), 소리/진동(유인·주의 분산), 빛/가시성(은신·탐색), 물질/재질(채집·장비·환경 변화). 유적 지키는 생물: 정면 교전, 소리 장치 유인, 은신, 이동 가능한 장애물 활용. 장소마다 특수 스크립트보다 일관된 속성. [도식](visuals/25-systemic-environment.svg).

## D26 채집
A 간편, B 모든 채집 직접 액션, C 일반 간편+특수 액션/도구/동료. 일반: 평범한 식물·광물 조각·작은 잔해·생물 흔적·소모 자원. 특수: 대형 광맥(채굴 도구/타격), 위험 식물(보호/추출), 고대 기계(해체/기술자/드론), 생물 샘플(진정/유인/생태 지식), 고열/전기/독성 지역(환경 대응·동료). 광물 발견→충격/균열→파괴/파편→획득, 진행 바만으로 끝내지 않음. 모든 채집 미니게임 금지. [도식](visuals/26-resource-gathering.svg).

## D27 운반
A 무제한 소지, B 엄격 적재, C 기본 간편+중요 자원 운반 위험. 일반 식물/광물 개인 인벤토리, 희귀 광물 제한 적재, 대형 유물 수송 장비/동료, 살아 있는 생명체 보호/생명 유지, 위험 물질 보관 용기 예시. 탐험 지속 또는 귀환의 선택. 모든 소지 제한·손실 수치 미결. [도식](visuals/27-resource-transport.svg).

## D28 착륙/귀환
A 자유 착륙/즉시 귀환, B 지정 착륙장/직접 귀환, C 자연스러운 착륙 지점+직접 귀환 기본+조건부 회수. 미개척지, 우주항, 유적 인근, 조건부 구조/수송. 착륙→탐험→유물→직접 귀환 또는 호출. 정찰선 좁은 지형, 수송선 대형 자원, 환경 대응 장비 극한 환경, 동료 파일럿 호출, 드론 반복 운반 보조. [도식](visuals/28-landing-return.svg).

## D29 발견 보상
A 자원·화폐·장비, B 장소·세계관·서사, C 복합 보상. 미지의 환경 자체, 고대 역사/기술, 생물 교감/동료, 교역로/정착지/세력 변화. 유적→희귀 자원(제작), 고대 정보(새 항성계), 외계 생물(교감/영입)→새 탐험. 작은 외계 생물이 행성 단서, 유물이 문명 교류 기회가 될 수 있음. STEP 4 종합: 호기심/발견→착륙/탐험→관찰/전투/채집→귀환/활용→성장/세계 변화→새 기회. 강제 순서 아님. [도식](visuals/29-discovery-reward-loop.svg).

## D30 성향 질문 — 대화 시안의 문항/선택지 원문
### 질문 1. 항해 중 정체불명의 조난 신호를 발견했다. 당신은?
- 위험을 감수하고 구조하러 간다.
- 주변을 탐색하고 신호를 분석한다.
- 구조에 필요한 장비를 먼저 준비한다.
- 다른 함선에 연락해 협력을 요청한다.

### 질문 2. 미지의 행성에서 가장 먼저 하고 싶은 일은?
- 새로운 생명체를 만나고 싶다.
- 숨겨진 유적을 발견하고 싶다.
- 희귀한 자원과 기술을 연구하고 싶다.
- 현지 문명과 교역하고 싶다.

### 질문 3. 당신에게 함선이란 어떤 존재인가?
- 자유롭게 여행하기 위한 수단
- 새로운 발견을 위한 탐사 기지
- 나만의 기술과 장비를 발전시키는 공간
- 동료들과 함께 살아가는 집
예시 추천 성향: 개척형 탐험가, 호기심 많은 수색대원, 기술 중심 엔지니어, 관계 중심 선장. 원래 대화 시안은 답변 인덱스 최빈값으로 표시; 동점 처리와 추천 알고리즘 미확정. A 직접 선택 / B 자동 결정 / C 추천+직접 수정. [실행 가능한 재구성 HTML](prototypes/character-creation-example.html), [시안 데이터](prototypes/character-creation-example.json), [설명 도식](visuals/30-character-creation.svg).

## D32 초기 함선 선택 — C 승인
A 동일 소형 함선(진입 단순, 초반 선택 차이 약함), B 3종 특화 함선(분명한 개성, 시작 역할 고정 우려), C 3종 기본 함선+제한적 초기 장비 구성 선택(추천). D31 질문 기반 추천/직접 수정과 연결하되 초기 직업으로 함선을 제한하지 않는다. 예시 3종: 소형 고속선(기동·회피/작은 화물), 소형 탐사선(센서·환경 조사/평범한 화력), 다목적 작업선(적재·수리/상대적으로 둔한 기동). 기본형의 장단점은 유지하면서 스캐너/추가 적재/기동 보조 중 제한적 시작 장비 선택 예시. 모든 함선으로 공통 핵심 활동(항해·착륙·탐험·교역·기본 전투)을 경험할 수 있어야 한다는 제안; 장기적으로 다른 함선 확보/개조 가능 방향. 함선 종류·정확한 슬롯/장비 수·초기 가격/수치·디자인 미확정. C 구조 승인. 장비 예시와 도식은 승인된 구현 아님. [자체 설명 도식](visuals/32-starting-ships-proposal.svg).

D32 대화 비교 게이지 원문 예시(기동성/적재량/탐지력/전투력/정비 능력 순서, 1–5 척도): 고속선 5/2/3/3/2, 탐사선 3/3/5/3/3, 작업선 2/5/3/3/5. 이는 그래프 표시용 상대 수치로 실제 밸런스 아님. 탐사선+추가 적재함으로 교역 시작 가능 예시.

## D33 직업·성장 — C 승인
A 고정 직업별 성장(역할 명확, 장기 자유 제한), B 직업 없는 자유 기술 성장(조합 자유, 초반 방향성 약화), C 초기 직업+자유로운 교차 기술 습득·전문화(추천). 예시: 파일럿이 탐색을 익혀 정찰 항해자, 엔지니어가 교섭을 익혀 기술 상인, 의무관이 생태 지식을 익혀 외계 생물 구조 전문가. 직업은 초기 강점, 후속 기술은 플레이/학습에 따라 다른 영역으로 확장하며 전문화에는 의미 있는 선택이 필요하다는 제안. 실제 직업 목록, 기술 습득 방식, 조건, 전문화 한계/재설정 및 수치는 미결. D30–32와 D22 유지.

D33 초기 직업 예시 표: 파일럿(조종·기동/항해·함선 전투), 수색대원(탐지·생태 지식/행성 탐험·채집), 엔지니어(제작·정비/개조·외계 기술), 의무관(치료·생명체 관리/구조·동료 보호), 외교관(협상·교섭/교역·세력 관계). 하이브리드 3종은 설명용 역할이지 공식 직업명 아님. [도식](visuals/33-cross-profession-growth.svg).

## D34 기술 습득·성장 — C 승인
A 공통 경험치·스킬 포인트(이해·보상 간편, 활동과 능력 간 연결 약함), B 행동 숙련 중심(활동과 성장 직접 연결, 반복 노가다 우려), C 실제 활동 숙련+의미 있는 기술 습득 선택(추천). 예시: 위험 구간 항해/회피로 조종 숙련, 미지 생태 조사로 탐색 숙련, 실제 수리/제작으로 기술 숙련, 구조/치료로 의학 숙련, 실제 협상으로 교섭 숙련. 숙련 또는 발견을 기반으로 기술을 고르거나 교관/동료/연구로 새로운 기술을 배우는 후보. 같은 행동 반복만으로 최적 성장 강제 금지, 실패의 학습 가치·비전투 성장 고려. 숙련 수치/자원·학습 조건·선택 횟수·반복 감소·전문화 제한 미확정.

D34 시안의 활동→숙련: 위험 항해·함선 회피→조종, 미지 장소·생태 조사→탐색, 제작·수리→기술, 치료·구조→의학, 교역·협상·중재→교섭, 지상 전투·무기 사용→전투. 기술 선택 인터랙션: 심층 탐지(숨은 신호/미세 단서→항성계 탐사 전문가), 생태 분석(습성/서식 환경→생태계 탐험 전문가), 고대 기술 판독(유물/장치 조사→고대 문명 탐사 전문가). 게이지/기술/명칭/해금은 예시. [도식](visuals/34-activity-skill-growth.svg) · [선택 시안 재구성](prototypes/skill-choice-example.html).

## D35 전문화 깊이와 성장 한계 — 미승인 제안
A 모든 능력을 제한 없이 최고 수준(자유도, 개성/동료 가치 약화 우려), B 고정 전문화 수와 영구 제한(역할 명확, 장기 경로 강제 우려), C 폭넓은 기술 습득+깊은 전문화에 의미 있는 투자와 기회비용(추천). 예시: 파일럿이 기본 수리와 교섭을 배워 혼자 기본 활동 가능, 고급 항법/전술에 더 깊게 투자; 고급 수리·치료가 필요하면 직접 더 배우거나 전문 동료를 영입. 장기 전환 허용 방향, 영구 직업 강제 금지. 투자 비용/상한/재설정/숙련 유지·활성 전문화 수/장기 올마스터 허용 여부 미확정. D33–34 유지.
