# v0.3 데스크톱 조작 확인 / 2026-11-17 KST

환경: Godot4.6.3 Linux 데스크톱, 960×720 게임 뷰, 편집기 내 실행.
CLI에 DISPLAY가 없어도 데스크톱 앱 실행/창별 입력 경로로 정상 동작했다.
프로젝트 관리자→Import→project.godot→F5를 실제 수행했다.
Sky 텍스트 입력은 포커스 없음으로 실패했지만, 관찰된 창에 바인딩한 네이티브 입력으로 해결.
Xorg 직접 생성/권한 상승/보안 우회는 하지 않았다.

## 실제 관찰한 상태 변화

1. R→A 약600ms→P: 캐릭터가 왼쪽으로 이동, 적재12/40, PAUSED 표시.
   체인쏘우 방향 변화/피격 체력바/재료 적층을 게임 화면에서 확인.
2. 위/오른쪽 이동으로 민트 납품패드 접근: BAG5, RAW11, MIX1, READY1,
   TILL0, LINE5. 과일별 가공과 줄이 그려짐.
3. 파란 응대패드로 이동/약1.6초 대기: BAG0, RAW10, MIX1, READY4,
   TILL15, LINE3. 손님 판매가 재고와 연결됨.
4. 이때 줄이 HUD 뒤에 가려진 화면 결함을 발견.
   가게 근처 카메라 추적 목표를 위쪽으로 이동하게 수정 후 F8/F5 재시작.
5. 수정본에서 R→W약1450ms→대기500ms→S약300ms→대기1600ms→P:
   $0, BAG0, RAW0, MIX0, READY3, TILL15, LINE3.
   손님 ID4/5/6이 HUD 아래 보임: 1/2/3 응대 후 줄이 앞당겨진 상태.
6. 재개→D약740ms→W약350ms→P: $20, READY2, TILL0, LINE3.
   손님ID5/6/7이 보임. 이동 중 추가1명 응대 후 총4판매 대금20을 회수함.
   금색패드의 COLLECT 표기도 $0으로 바뀜.

시간은 UI 키 홀드 지시값이고 실제 영상 계측/정밀 시간측정이 아니다.
스크린샷으로 단계별 상태를 관찰했으며 지속 녹화/fps/오디오 청음은 하지 않았다.
원본과의 프레임 동등성/인간 타격감 선호도/폰/Mac/지속 플레이 성능은 미검증.
최종 pause 중 카메라 추적 멈춤 수정은 headless 회귀로 확인했고 재수동 조작은 미실행.

  PAUSED / Saw OFF. 손님ID2/3/4/5가 새 HUD아래 보임(응대패드 바깥쪽 근처).
- 5→P: Motor false / Saw OFF인채 가공·응대는 계속됨.

새 음향을 켠 실행에서 수확/가공/고객 흐름과 UI가 동작함을 확인했으나
실제 음성을 청음하거나 지속 녹음하지 않았다. CUT 실시간 화면 포착은 미실행,
명중 부하음 분기는 자동 검사로 확인. 장치의 실제 출력파형·클리핑도 미측정.
최종 동시음성4→2/충격음 gain0.75 변경은 자동 PCM 상한검사만 했고 재GUI확인은 미실행.

# v0.5 실제 고용/자동 판매
최신ZIP기반 run05를 새 프로젝트로import후 F5. 이전 run04 게임은 F8로 중지하고
신규 편집기를 창목록에서 구분해 실행. 화면에 새 E/HIRE CASHIER $30 버튼 표시.
1. 기존 수확재료를 가지고 W1450ms→대기800ms→S300ms→대기4500ms→P:
   BAG0 RAW14 MIX1 READY8 TILL35 LINE1. 응대 중 현금은 아직 지갑0.
2. 재개→D740ms→W350ms로 금색패드 회수→D650ms로 보라색패드→E→P:
   지갑10, RAW6 MIX1 READY15 TILL0 LINE2. 이동 초반 추가판매를 포함한40회수 후
   고용비30차감. CASHIER WORKING 버튼, AUTO SERVICE 패드, 계산원도형이 보임.
3. 재개→S1400ms로 과일구역 복귀→대기1700ms→P:
   지갑10 BAG9 RAW0 MIX0 READY18 TILL20 LINE1. 플레이어는 응대패드에서 멀리 있고
   수확하면서 계산원이 새 판매대금20을 쌓은 상태를 실제 화면에서 확인.
고용은 E키로 실행했으며 마우스/터치 버튼 경로의 실기기 검증은 미실행.
키홀드 시간은 요청값이며 정밀플레이 계측이 아님. 사람손맛/청음/폰/Mac은 미검증.
