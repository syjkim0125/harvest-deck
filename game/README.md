# VOID CARAVAN / FIRST LIGHT
New Godot 4.6 project (clean-slate M1 playtest, not the retired SF game).
Open project.godot in Godot 4.6.3 and press F6/F5 (F5 runs flight.tscn).
Portrait touch: drag to steer, release to coast; approach objects then tap the contextual action. Desktop: mouse drag or WASD/arrows, E to interact, Esc pause. Audio unlocks after touch; mute at top. Save lives in user://first_light_v1.json, no wall-clock simulation. Landing is a temporary arrival screen, not ground gameplay.
Temporary ship / system names, parameters, art, and initial scenario for user evaluation. No final art or onboarding approval implied. D02,D07–08,D11–12,D90–95. NPCs, discoveries, salvage, optional arrival/return, persistent position/time. Not yet crew, combat, trade economy, galaxy map or M2 surface movement.
All textures are original generated SVGs, not copied from reference games. Environmental cues and optional approach follow approved Koster / Zelda exploration / direct voyage principles; source mapping docs/planning/THEORY_APPLICATION.md and REFERENCE_EVIDENCE.md. Audio synthesized locally.
